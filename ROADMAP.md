### V1: The True Mycelial Network (P2P + IPFS)
- **Концепція:** Симуляція має вийти за межі одного браузера (Localhost). `PhaseNetwork` зараз імітує мережу, але справжня мета — об'єднання тисяч вкладки браузерів по всьому світу у єдиний **Mega-Torus**.
- **Імплементація:** Використання WebRTC Data Channels (libp2p) для обміну Плазмідами між нодами. IPFS використовуватиметься для холодного зберігання геномів Apex-організмів (Akashic Records).

### V2: LLM Autopoiesis (Самопрограмування Системи)
- **Концепція:** Наступна мета — дати можливість Apex-організмам генерувати текстові промпти до зовнішнього LLM, запитуючи фіксовані шматки WASM-коду, які змінять самі правила фізики Курамото. 
- **Імплементація:** Підключення OpenAI / Anthropic API всередині `SovereignOracle`. ATP (Енергія) симуляції трансформується у реальні API-токени. Якщо в організму немає реальної цінності, він не зможе "думати" через LLM.

### V3: Metaphysical ZK-Proofs (Криптографічний захист Еволюції)
- **Концепція:** Оскільки OMEGA-64 стає децентралізованою, ми маємо гарантувати, що чужі браузери не зламали закони фізики, щоб генерувати безкінечну енергію.
- **Імплементація:** Інтеграція ZK-Snarks. Швидкість виконання кожного сектору підписуватиметься і перевірятиметься сусідами.

## 🔬 TACTICAL VECTORS (Тактичні задачі найближчих Епох)

### T1: WebWorker Decoupling for Macro-Torus Scaling
- Повністю винести `SovereignOracle` у SharedWorker. Передати `wasmMemory` через `SharedArrayBuffer` для забезпечення Zero GC Pauses на UI.
### T2: Quadtree / Frustum Culling Visuals
- Імплементувати QuadTree структуру в `PhaseWebGPUObserver`, перераховуючи геометрію тільки в полі зору камери, а макро-масштаб рендерити як розмиті Mycelial Heatmaps (підготовка до 1024x1024 Тора).
### T3: The "Phylogenetic Tree" UI Integration
- Зробити повномасштабну D3.js Canvas-панель, що рендерить еволюційне дерево походження плазмідів у реальному часі.
### T4: WebRTC P2P Data Channels Setup
- Інтегрувати Deno Signaling Server і встановити прямі з'єднання між клієнтами для обміну структурою `Term`.
### T5: Pure Integer Determinism (No Float64)
- **Проблема:** Хоча WASM і WebGPU зараз працюють стабільно, операції з рухомою комою (IEEE 754) можуть давати мікроскопічні відхилення при макро-масштабуванні на різних GPU та CPU архітектурах.
- **Рішення:** Повне переписування радіального резонансу Курамото та фазової теплової дифузії на 10-bit/20-bit Fixed-Point Q-Math (категорична відмова від `float64` та `f32` у всіх шейдерах та Rust-ядрі). Абсолютна, побітова цілочисельна детермінованість Матриці.
