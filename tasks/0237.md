## 4. Резонансні Правки (Actionable Edits)

### [P0 - Критично] Escrow + Falsifier-Gated Unlock

- **Проблема:** Енергія блокується без детермінованого умови повернення → ризик
  dead capital або централізованого арбітражу.
- **Філософія/Фізика:** Ставка — це тимчасовий локальний мінімум потенційної
  енергії. Вона повертається тільки при фазовій синхронізації з мережею
  (резонанс `r > θ`) або вирішенні фальсифікатора.
- **Імплементація:**

```typescript
// jazz/src/stake_resolver.ts
interface StakedChord {
  primary: string;
  stake_q16: number; // 0..65536
  falsifier: string;
  receipt_hash?: string;
  lock_tick: number;
}

function resolveStake(
  chord: StakedChord,
  resonance_r: number,
  threshold_q16: number,
): {
  returned: number;
  slashed: number;
  compost: number;
} {
  const r_norm = Math.min(resonance_r, 1.0);
  // Крива повернення: лінійна до threshold, потім експоненційний бонус
  const payout_ratio = r_norm < threshold_q16 / 65536
    ? r_norm
    : threshold_q16 / 65536 + Math.pow(r_norm - threshold_q16 / 65536, 1.5) * 2;

  const returned = Math.floor(chord.stake_q16 * payout_ratio);
  const slashed = chord.stake_q16 - returned;

  // Термодинаміка: слеш → компост (доступний для нових агентів)
  return { returned, slashed, compost: slashed };
}
```

### [P1 - Архітектурно] Multi-Oracle Adjudication без Single Judge

- **Проблема:** Один арбітр = централізація. Collusion моделей = маніпуляція
  ставками.
- **Фізика:** Використовуємо резонансну різницю між оракулами як proxy для
  якості. Якщо 3+ оракули дають `|r_i - r_j| < δ` → консенсус. Якщо розкид
  великий → partial slash → compost.
- **Імплементація:**

```rust
// omega_v2/src/senate_adjudication.rs
pub fn compute_consensus_stake(replies: &[OracleReply], delta_q10: u32) -> u32 {
    if replies.len() < 2 { return 0; }
    let mut r_values: Vec<i32> = replies.iter().map(|r| r.resonance_q10 as i32).collect();
    r_values.sort();
    // Медіанна різниця (робастна до викидів)
    let med_diff = (r_values[1] - r_values[0]).abs();
    if med_diff < delta_q10 as i32 {
        65536 // Full return
    } else {
        // Partial slash proportional to divergence
        (65536u32.saturating_sub(med_diff as u32 * 32)).max(16384)
    }
}
```

**Концепт: Фазовий Стейкінг як Хвильова Інтерференція**

Уявіть ставку не як число, а як **амплітуду хвилі** `A ∈ ℂ`. Коли агент генерує
output, його хвиля накладається на поле мережі. Якщо фаза збігається (`Δφ ≈ 0`),
відбувається конструктивна інтерференція: `A_total = Σ A_i`, ставка повертається
з бонусом, енергія конденсується в стабільний атрактор. Якщо фаза протилежна
(`Δφ ≈ π`), хвилі гасять одна одну: `A_total → 0`, ставка перетворюється на
ентропію, яка розсіюється в термальний пул. Це не метафора — це **математичний
ізоморфізм** до рівняння Курамото. Економіка стає фізикою хвиль, а "мудрість" —
резонансною когерентністю. Порожній центр залишається порожнім, бо ніхто не
контролює фазу: вона емерджентна, а ставка — лише амплітуда, яку ви готові
поставити на свою координату в спектрі.
