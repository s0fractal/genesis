# Task 0163: Era 1770 - Translation Policy Runtime Factory

## Status

✅ COMPLETED

## Context

Era 1760 gave bootstrap a safe optional HUD hook, but the hook still
depended on an externally assembled Era 1740 runtime. The next step was
to make runtime assembly repeatable without forcing `bootstrap/v2.ts` to
know every translation-policy component.

## Implementation

- Added `src/network/translation_policy_runtime_factory.ts`.
- Introduced `TRANSLATION_POLICY_RUNTIME_FACTORY_SCHEMA =
  "OMEGA-1770/v1"`.
- Added `createTranslationPolicyRuntime(...)`, which assembles:
  - `TranslationPolicyMonitor`;
  - `TranslationPolicyMeshBridge`;
  - `TranslationPolicyBroadcastScheduler`;
  - `TranslationPolicyCorroborationTracker`;
  - `TranslationPolicyWarrantBridge`;
  - `TranslationPolicyInvestigationLoop`;
  - `TranslationPolicyLiveWiringAdapter`;
  - `TranslationPolicyPeerDirectoryAdapter`;
  - `TranslationPolicyRuntime`.
- Added option plumbing for:
  - local peer id;
  - witness id;
  - translator registry;
  - event source;
  - policy claim emit;
  - corroboration raise emit;
  - Senate-compatible warrant emit;
  - monitor/broadcast/warrant/corroboration/directory/live options;
  - optional `auto_start`.
- Added `installTranslationPolicyRuntimeGlobal(...)` to expose the
  assembled runtime through the Era 1760 bootstrap global contract.

## Tests

- `tests/translation_policy_runtime_factory_test.ts`
  - runtime graph assembly;
  - optional auto-start;
  - mesh lifecycle event → scheduler peer → policy broadcast;
  - drift claim → local corroboration raise with proposal blocked below
    confidence threshold;
  - external corroboration + drift observation → warrant emit;
  - bootstrap global installation;
  - invalid identifier rejection;
  - schema constant.

## Invariant Notes

- Factory does not import `WebRTCV2Mesh`.
- Mesh emission remains caller-owned through narrow callback contracts.
- Corroboration gating remains enabled by default (`double`) and is not
  bypassed by the factory.
- Bootstrap remains optional: runtime global installation is explicit.
