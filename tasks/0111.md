# Task 0111: Era 1250 — Composite Health Broadcast

## Status: COMPLETED | Priority: HIGH

## Context
Era 1240 made every relay compute a composite mesh health score
in `[0, 1]`. Era 1250 makes that score BROADCASTABLE: a new
SporeFrame type carries the composite + breakdown counts so peer
relays can compare composites the same way they compare resilience
digests (Era 1200). When two relays observing the same physical
mesh disagree on the composite score by ≥0.20, that's a
**meta-partition** — the relays don't even agree on what
"healthy" means.

## Objective
Add `FRAME_TYPE_COMPOSITE_HEALTH = 6` to the wire format. Wrap the
composite score (Q16) + band code + alarm/suspect/quarantine counts
+ redundancy contribution into the SporeFrame's existing payload
slots. Add a `CompositeHealthMonitor` that observes peer composites
and surfaces meta-partition alarms.

## Design Notes
- **Why threshold 0.20 absolute (not 10% of max)?** Composite
  scores already aggregate noise across multiple inputs;
  disagreement on composite is MORE signal-rich than on any
  single underlying metric. A stricter threshold avoids
  false-positive alarms when different relays observe slightly
  different but compatible mesh states.
- **Why 4 separate u8 counts in `payload_b`?** They fit in one
  u32 (band + 3 counts × 1 byte = 32 bits). Clamping at 255 is
  sufficient — operationally, more than 255 of any signal in a
  single window means a fundamentally broken mesh, where the
  exact count doesn't matter for routing decisions.
- **Why broadcast composite when underlying metrics already
  broadcast?** The composite is a SEMANTIC signal — it represents
  the relay's overall judgment about the mesh, not raw counts.
  Two relays may agree on raw counts but disagree on weights
  (configured via `CompositeOptions`); broadcasting composites
  surfaces that semantic disagreement directly.
- **Why is it "meta"-partition?** A normal partition = relays
  see different mesh states. A meta-partition = relays see
  similar states but draw different conclusions. The latter
  signals a deeper integrity problem (mis-configured weights,
  drifted scoring formula, compromised aggregator).
