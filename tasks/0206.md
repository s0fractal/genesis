## 4. Технічна специфікація Temporal Binding

### 4.1. Bitcoin Block Oracle (BBO)

```rust
// omega_v2/src/bitcoin_oracle.rs (no_std compatible)
pub struct BitcoinBlockOracle {
    /// Хеші блоків, що формують genesis entropy
    pub block_hashes: [BitcoinBlockHash; 6],
    /// Target block heights (зафіксовані на старті)
    pub target_heights: [u32; 6],
    /// Merkle root цих блоків (verified via SPV)
    pub spv_merkle_root: [u8; 32],
}

impl BitcoinBlockOracle {
    /// Обчислює Genesis Entropy з історичних блоків
    pub fn compute_genesis_entropy(&self) -> [u8; 32] {
        let mut hasher = Sha256::new();
        for hash in &self.block_hashes {
            hasher.update(hash);
        }
        hasher.finalize().into()
    }
    
    /// Перевіряє, чи нода використовує канонічний GE
    pub fn verify_canonical(&self, claimed_ge: &[u8; 32]) -> bool {
        *claimed_ge == self.compute_genesis_entropy()
    }
}
```
