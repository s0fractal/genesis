# Task 0165: Era 1790 - Translation Policy Bootstrap Installer

## Status

✅ COMPLETED

## Context

Era 1770 provided a runtime factory. Era 1780 provided a mesh emit
adapter. Bootstrap still had to know how to compose both if an operator
wanted the live translation-policy path enabled.

## Implementation

- Added `src/bootstrap/translation_policy_bootstrap_installer.ts`.
- Introduced `TRANSLATION_POLICY_BOOTSTRAP_INSTALLER_SCHEMA =
  "OMEGA-1790/v1"`.
- Added `installTranslationPolicyBootstrap(...)`, an opt-in composer
  that:
  - accepts a mesh-like `enqueuePlasmid` surface;
  - builds the Era 1780 mesh emit adapter;
  - builds the Era 1770 runtime factory result;
  - installs the runtime into the Era 1760 global contract;
  - optionally installs HUD config;
  - auto-starts the runtime by default;
  - returns explicit status instead of throwing on disabled/invalid
    config.
- Wired `src/bootstrap/v2.ts` to call the installer only when
  `window.__OMEGA_TRANSLATION_POLICY_BOOTSTRAP__` is present and
  enabled.

## Tests

- `tests/translation_policy_bootstrap_installer_test.ts`
  - disabled config remains inert;
  - missing peer ids do not throw or install;
  - runtime installs, starts, and sets HUD global;
  - installed runtime broadcasts through mesh adapter;
  - `auto_start: false` is respected;
  - adapter construction failures are contained;
  - schema constant.
