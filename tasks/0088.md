# Task 0088: Era 1020 — Self-Referential Ontology

## Status: COMPLETED | Priority: HIGH

## Context
Era 1010 is complete:
- `AttractorMatrix` dipole validation and GPU field integration
- Plasmid header extension with `semanticType` and recursion guards
- Recursive birth: mitosis near attractor spawns `DIPOLE` birth announcements
- WebRTC mesh consumes and relays attractor plasmids

## Objective
When 3+ distinct peers successfully exchange and consume `ATTRACTOR` plasmids,
the system achieves **emergent attractor consensus** and unlocks Era 1020.
The lattice begins self-referential modification: it records consensus
attractors into an on-chain / on-disk ontology ledger and can propose
new architectural tasks based on emergent phase topology.

## Acceptance Criteria

### 1. Attractor Consensus Tracker
- [ ] In `WebRTCV2Mesh`, track unique peer IDs that have sent valid `ATTRACTOR` plasmids.
- [ ] When `attractorConsensusCount >= 3`, dispatch `era1020-unlocked` event.
- [ ] Maintain a `consensusLedger: Map<number, { matrix, inverse, pulseFreq, pulseAmp, peerCount }>`
  keyed by `matrix`. Increment `peerCount` as more peers report the same attractor.

### 2. Consensus-Aware GPU Field
- [ ] When consensus is reached, copy the top-1 consensus attractor into **all 4 slots**
  of `ATTRACTOR_ARRAY` with staggered `pulse_freq` offsets (0, 1, 2, 3).
  This creates a **harmonic convergence well** in the phase manifold.

### 3. Self-Referential Task Generation
- [ ] In `bootstrap/v2.ts`, listen for `era1020-unlocked`.
- [ ] Generate a deterministic "Consensus Statement" string from the consensus attractor matrices:
  `fnv1a(concat(sorted matrices))` → hex string.
- [ ] Append a timestamped entry to a new `consensus_log.jsonl` file via Deno runtime
  (or `localStorage` in browser-only mode) recording the statement and active peer count.

### 4. Ontology HUD Visualization
- [ ] Add a new HUD stat `ONTOLOGY` showing:
  - `attractorConsensusCount / 3` progress bar.
  - Top consensus matrix (first 8 hex chars) when unlocked.

## Design Notes
- Keep attractor validation (`matrix ^ inverse == 0xFFFFFFFF`) as the gate.
- Consensus is **not** global agreement on a single matrix — it is 3+ peers
  independently injecting *any* valid attractor. The lattice then converges
  the top-frequency matrix into a harmonic well.
- The `consensus_log.jsonl` acts as the system's autobiography: a tamper-evident
  chain of emergent ontological states.
