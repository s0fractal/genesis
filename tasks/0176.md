# Task 0176: Era 1900 - Translation Policy Replay Digest Quorum HUD

## Status

✅ COMPLETED

## Context

Era 1890 wires replay-digest claims into a live quorum tracker. Operators
still needed a compact pure formatter for snapshots and live telemetry
without adding DOM slots or runtime ownership.

## Implementation

- Added `src/network/translation_policy_replay_digest_hud.ts`.
- Introduced `TRANSLATION_POLICY_REPLAY_DIGEST_HUD_SCHEMA =
  "OMEGA-1900/v1"`.
- Added `formatTranslationPolicyReplayDigestHud(...)` with fields:
  - quorum band/count;
  - consensus digest and agreement percent;
  - dissenting peers;
  - claim/local-emission IO health.
- Added helpers:
  - `translationPolicyReplayDigestHudBand(...)`;
  - `translationPolicyReplayDigestHudGlyph(...)`;
  - `translationPolicyReplayDigestHudFields(...)`;
  - `formatReplayDigestDissenters(...)`;
  - `q16ToPercent(...)`.
- Band rules:
  - local claim emit failure → `blocked`;
  - dissenters → `drift`;
  - no claims, lone quorum, or malformed claims → `watch`;
  - otherwise → `nominal`.
