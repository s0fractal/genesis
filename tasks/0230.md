### 1. Фізика (Lattice + Kuramoto + Biology)

**Сильні сторони**:

- Тороїдальна топологія + integer-only hot path (Q10/Q20 fixed-point) —
  правильно для детермінізму.
- Kuramoto coupling з energy-weighting та dipole/attractor rules дає emergent

- Митоз, metabolic burn (popcount/genome), resonance replenish — базова
  дарвінівська економіка.

- Power-of-Two alignment + hardware-aware ceilings (VRAM budget) у V2 —
  правильний напрямок.

**Проблеми та технічний борг** (з audit + коду):

- Багато magic numbers (mitosis 2000/1000, burn divisors, thresholds 10/40,
  resonance 64/150 тощо). Вони не виводяться з topology.q_phase чи Q-scale.
- Genome зараз слабо використовується (8→32-bit покращили, але мутація XOR mask
  детермінована, а не стохастична).
- Phase drift для негативних freq (CRIT-1) був фіксом — переконайся, що всі
  arithmetic shifts правильно обробляють знак.
- Aggregate functions (total_amplitude тощо) часто тільки по max rho — це bias.
  Має бути `_all_rho` + weighted за energy.
- WebGPU compute: ping-pong buffers добре, але cold-start (oldMeanField) і sine
  LUT write кожний кадр (були фікси) — продовжуй zero-allocation mindset.

**Пропозиція (Physics Vector)**:

  (але ок для anchors).

  routing ще в progress.
