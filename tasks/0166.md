# Task 0166: Era 1800 - Translation Policy Runtime Tick Hook

## Status

✅ COMPLETED

## Context

Era 1790 allowed bootstrap to install the translation-policy runtime,
but the render loop still did not drive `runtime.tick(...)`. Outbound
policy broadcasts therefore depended on external caller code.

## Implementation

- Added `src/bootstrap/translation_policy_runtime_tick_hook.ts`.
- Introduced `TRANSLATION_POLICY_RUNTIME_TICK_HOOK_SCHEMA =
  "OMEGA-1800/v1"`.
- Added `TranslationPolicyRuntimeTickHook`, which:
  - accepts any runtime-like source exposing `tick(now_ms, max_peers)`;
  - throttles calls with `min_interval_ms`;
  - caps fanout with `max_peers_per_tick`;
  - contains runtime exceptions;
  - returns explicit tick/cooldown/disabled/error status.
- Extended `TranslationPolicyBootstrapInstallOptions` with `tick`.
- Installer now writes `__OMEGA_TRANSLATION_POLICY_TICK__` to the
  bootstrap global, defaulting to enabled for opt-in installs while
  allowing `tick: false`.
- Wired `src/bootstrap/v2.ts` to create and invoke the tick hook every
  frame, independently from the HUD hook.

## Tests

- `tests/translation_policy_runtime_tick_hook_test.ts`
  - disabled default;
  - enabled runtime tick with max-peer cap;
  - interval throttling;
  - runtime exception containment;
  - null-source factory inertness;
  - partial option merge;
  - schema constant.
- Extended `tests/translation_policy_bootstrap_installer_test.ts` for
