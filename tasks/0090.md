## Acceptance Criteria

### 1. ZK Guest Resurrection
- [ ] `omega_zk_guest` builds for `riscv32im-succinct-zkvm-elf` via
  `cargo prove build` (SP1 toolchain).
- [ ] Mode 0 (PoUW) and Mode 1 (Resonance) modes from `src/main.rs`
  remain valid; add Mode 2 for `darwinian_mitosis`.

### 2. Mode 2: Mitosis Proof
- [ ] Reads: parent agent (32 bytes), mitosis seed (u32), expected child.
- [ ] Re-runs the integer-only mitosis math via `lattice.rs` paths.
- [ ] Asserts the derived child matches the expected child bit-for-bit.
- [ ] Commits `(parent_genome, child_genome, mitosis_seed)` as the proof
  receipt.

### 3. Host-Side Proof Generation
- [ ] `tools/zk_prove_mitosis.ts` (Deno) takes a parent+seed+child triple
  and produces an SP1 proof bundle (`.proof.bin`).
- [ ] Bundles are addressable by `(parent_genome, mitosis_seed)`.

### 4. Mesh Integration
- [ ] `PlasmidPayload` gains an optional `proofHash: number` field.
- [ ] DIPOLE birth-announcement plasmids carry the FNV-1a hash of the
  proof bundle. Mesh peers fetch+verify before accepting the new agent.
- [ ] Add `tools/zk_verify.ts` for round-trip CI testing.

### 5. Tests
- [ ] `cargo prove build && cargo prove run --proof receipt.bin` exits 0
  on the canonical golden-trace mitosis.
- [ ] Cross-language anchor: prove a known mitosis triple, then verify
  the receipt from JS via SP1's wasm verifier.
