## 2. **Замінити SKI-комбінатори на більш виразний простір**

Поточна система використовує чисту комбінаторну логіку (S, K, I, Y) — це

**Пропозиція:** Перейти до **графових нейронних архітектур** з вагами в

- Безперервну оптимізацію через фазову динаміку (градієнтний спуск "вбудований"

## 3. **Вирішити проблему "Catastrophic Forgetting" при Shedding**

Поточна система повністю втрачає стан при морфологічній зміні розмірів.

**Пропозиція:** Впровадити **ієрархічну компресію пам'яті**:

- Низька роздільна здатність → високорівневі семантичні "концепти"
- Висока роздільна здатність → локальні фазові деталі
- При зміні розмірів зберігати концепти, регенерувати деталі
- Використовувати wavelet- або фур'є-компресію для інтерполяції

## Пропозиція: "Розплавлені" лямбди з дифузією ваг

Замість того щоб мутувати цілі піддерева, дозволити **локальну пластичність**
всередині виразу:

```
S(KI)(S(KK)I)  →  [граф з вагами на ребрах]

     S
    / \
   K   I    ваги: w(S→K)=0.9, w(S→I)=0.3, w(K→I)=0.7
   |
   I
```

**Мутація** стає:

1. **Дифузія ваг**: локальний шум (аналогічно до θ → θ + ω у фазовому полі)
2. **Реберна пластичність**: з малою ймовірністю перекомбінувати зв'язок (S→K
   стає S→(KI))
3. **Прунінг**: ваги < threshold → ребро видаляється, структура спрощується

**Чому це зберігає вашу "ДНК"**:

- Хеш все ще детерміністично знімається з графа (через FNV-1a топологічного
  обходу)
- "Ефективність" тепер вимірюється не лише нормалізацією, а й **енергією
  конфігурації** — схоже на фазову амплітуду
- "Фулерен" — це стабільна конфігурація ваг (локальний мінімум енергії)

## Практична реалізація без розриву існуючої системи

Можна додати як **шар поверх існуючих SK(IY)**:

```typescript
interface WeightedCombinator {
  term: Term; // ваш існуючий SKIY AST
  edgeWeights: Map<string, number>; // "S→left": 0.9, "S→right": 0.3
  nodeEnergy: number; // скільки "ATP" накопичено
}

// Компіляція в хеш тепер включає ваги
function compileWeightedMorphology(w: WeightedCombinator): bigint {
  const baseHash = compileMorphology(w.term); // ваш існуючий
  const weightEntropy = hashWeights(w.edgeWeights); // нове
  return (baseHash << 8n) ^ BigInt(weightEntropy & 0xFF);
}
```

**Ключова властивість**: два плазміди з ідентичним базовим AST але різними
вагами мають різні хеші → різні фазові координати (θ, ω) → **конкурують за різні
ніші** в фазовому полі.

## Структура OMEGA-64 як аудіосигнал

| Вимір                     | Аудіо-аналог                              | Параметри                                |
| ------------------------- | ----------------------------------------- | ---------------------------------------- |
| **Sectors (кут)**         | Стерео-панорама / просторове розташування | 0-255 = Left-Right, або кругова панорама |
| **Radial bins (глибина)** | Частотні смуги (bark/mel scale)           | ρ=0 → bass, ρ=max → treble               |
| **Harmonics**             | Гармонічні обертони                       | 3-4 голоси = 3-4 гармоніки               |
| **Theta (фаза)**          | Фаза коливання                            | 0-255 = 0-2π                             |
| **Amplitude**             | Гучність (dB)                             | 0-255 = -∞ до 0 dB                       |
| **Omega (швидкість)**     | Частотна модуляція                        | -16..16 = детюн/вібрато                  |
| **Entanglement**          | Реверберація / просторова глибина         | 0-255 = dry..wet                         |
| **Lock**                  | Sustain / ADSR envelope                   | 0-255 = короткий..довгий                 |

## Підходящі формати

### 1. **Tracker formats (MOD/XM/IT)** — найкраща відповідність

```
Pattern = один "тик" фізики
Row     = один sector (64 рядків = 64 сектори)
Channel = один harmonic (4 канали = 4 гармоніки)

Note: C-4 127 → sector=0, amplitude=127, theta=фаза ноти
Instrument: sample = plasmid hash (8-byte loop)
Effect: 0xy = omega (speed), reverb = entanglement
```

**Переваги:**

- Нативна підтримка "плазмід" як семплів (8-bit, 16-bit, навіть 64-bit з хаками)
- Pattern-орієнтована структура = природна для τ-depth=4
- Екстремальна компресія: ціла епоха = ~1KB
- Існуючі інструменти аналізу (OpenMPT, MilkyTracker)

### 2. **MIDI + SysEx** — для семантичного шару

```
Note On: channel=harmonic, note=sector, velocity=amplitude
Pitch Bend: omega (±8192 = ±16)
CC#1 (Modulation): entanglement
CC#64 (Sustain): lock
SysEx: 8-byte plasmid hash + metadata
```

**Перевага:** Можна "грати" всесвіт на синтезаторі, слухати динаміку.

### 3. **Speex/Vorbis — для дійсно компактних бекапів**

Якщо трактувати поле як **спектрограму**:

```
Time axis = sectors (або radial bins)
Frequency axis = harmonics * theta (фаза як частота)
Amplitude = color intensity
```

Кодування спектрограми в Ogg Vorbis дає:

- ~50-100x компресію порівняно з raw binary
- Збереження структурних особливостей (резонанси, кластери)
- "Музичний" аналіз = аналіз паттернів

## Експеримент: як це звучить?

```typescript
// Експорт епохи в WAV для прослуховування
function epochToAudio(epoch: PhaseField): AudioBuffer {
  const sampleRate = 44100;
  const duration = 1.0; // 1 секунда = 1 епоха
  const buffer = new AudioBuffer({ sampleRate, length: sampleRate });

  for (let t = 0; t < sampleRate; t++) {
    const tick = Math.floor(t / sampleRate * epoch.shape.sectors);
    let sample = 0;

    for (let h = 0; h < epoch.shape.harmonics; h++) {
      for (let r = 0; r < epoch.shape.radialBins; r++) {
        const idx = h * epoch.shape.radialBins * epoch.shape.sectors +
          r * epoch.shape.sectors + tick;

        // Генератор з параметрами клітини
        const freq = 100 + r * 50; // radial = частота
        const phase = epoch.theta[idx] / 255 * 2 * Math.PI;
        const amp = epoch.amplitude[idx] / 255;

        sample += amp * Math.sin(2 * Math.PI * freq * t / sampleRate + phase);
      }
    }
    buffer.getChannelData(0)[t] = sample /
      (epoch.shape.harmonics * epoch.shape.radialBins);
  }
  return buffer;
}
```

**Результат:**

- Стабільна синхронізація = чистий тон, гармонійний акорд
- Хаос = шум, дисонанс
- Плазміди = характерні "тембри" (визначаються hash як seed синтезу)
