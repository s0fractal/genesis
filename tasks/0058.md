1. **Найкритичніше зараз (5–10 хв роботи)**

     `if (!device) { /* CPU-only path */ }`.\
     Зараз `device = null` передається, але багато методів все ще припускають,
     що GPU є. Без цього fallback буде падати.

     `execute_phase_lattice_tick` (або хоча б раз на 100 тіків) і логувати

     `plasmid_collisions`. Зараз race conditions можливі при ін’єкції плазмідів.

     dev-режимі).

     порівнює підписи.
