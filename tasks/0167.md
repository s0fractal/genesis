# Task 0167: Era 1810 - Translation Policy Bootstrap Telemetry Snapshot

## Status

✅ COMPLETED

## Context

By Era 1800, translation-policy bootstrap could install, tick, and show
HUD telemetry. Operational diagnostics were still scattered across the
installer result, runtime telemetry, tick hook result, and mesh-emitter
counters.

## Implementation

- Added `src/bootstrap/translation_policy_bootstrap_telemetry.ts`.
- Introduced `TRANSLATION_POLICY_BOOTSTRAP_TELEMETRY_SCHEMA =
  "OMEGA-1810/v1"`.
- Added `translationPolicyBootstrapTelemetrySnapshot(...)`, a stable
  diagnostic object containing:
  - install status/reason/error;
  - last tick status/reason/error;
  - broadcast sent/failed/unchanged/cold counts from the last tick;
  - runtime telemetry snapshot;
  - mesh-emitter sent/failed counters.
- Wired `src/bootstrap/v2.ts` to publish
  `window.__OMEGA_TRANSLATION_POLICY_TELEMETRY__` every frame.

## Tests

- `tests/translation_policy_bootstrap_telemetry_test.ts`
  - disabled install returns null runtime/emit telemetry;
  - installed runtime reports runtime + emit telemetry before tick;
  - tick result contributes broadcast counters;
  - runtime-error tick is surfaced without throwing;
  - schema constant.
