ZK-згортки фізики (Mode 3) та Zero-Copy бінарний RPC. Фундамент ізольовано від
недетермінізму (Q10/Q20 математика, хардкод-LUTи).

Оскільки ваш поточний вектор — **"Spine Compression" (стиснення хребта)**, вам
більше не потрібні нові абстракції чи протоколи. Час застосувати принцип
**Уробороса (Замикання Петлі)** — взяти вже існуючі виходи системи і замкнути їх
на її ж входи. Кожен байт має працювати на кількох онтологічних рівнях

### 🧠 1. Термодинамічна Епістемологія (The Cost of Oracle Thought)

**Філософія:** Свідомість не існує окремо від матерії. Наразі ваш LLM-Оракул у
`oracle_worker.ts` має статичну `temperature: 0.7`. Це порушує принцип єдності.
Здатність Оракула до "галюцинацій" або "логіки" має бути прямою функцією від
ентропії фазового простору Тора. **Інженерія (Мінімальна зміна):** Замкніть
параметр `currentEntropy` на `temperature` Мовної Моделі. У
`src/workers/oracle_worker.ts`:

```typescript
const dynamicTemp = Math.max(0.1, Math.min(1.0, data.currentEntropy / 10.0));
const reply = await engine.chat.completions.create({
  messages: [{ role: "user", content: contentPayload as any }],
  temperature: dynamicTemp, // Термодинаміка диктує стан розуму
});
```

_Імпакт:_ Коли Тор кристалізується (низька ентропія), Оракул стає холодним,
детермінованим і суворим. Коли Тор розпадається в хаосі (висока ентропія),
Оракул впадає в делірій і починає генерувати дикі, нестандартні AST-мутації для
порятунку системи.

### 🧬 2. Епігенетична Термодинаміка Смерті (Rare Information = High Heat)

**Філософія:** Згідно з Принципом Ландауера, втрата інформації вивільняє тепло.
`CompostConsumer` зараз проектує смерть агентів назад у решітку як енергію. Але
смерть масового клону не має дорівнювати смерті унікального, древнього геному.
Втрата рідкісної інформації повинна розривати фазовий простір. **Інженерія:**
Використайте існуючий FFI `v2_get_epigenetic_bias`. У
`src/ontology/semantic_layer.ts`:

```typescript
public projectCompost(event: CompostEvent) {
    // ...
    // Чим рідше зустрічалися біти цього геному в історії, тим потужніший вибух
    const bias = this.engine.getEpigeneticBias(event.genome % 32);
    const total = this.engine.getEpigeneticTotal() || 1;
    const rarityMultiplier = 1.0 + (1.0 - (bias / total)) * 10.0; 
    
    const energy = Math.min((event.energy_at_death || 100) * 2 * rarityMultiplier, 60000);
    // ...
}
```

_Імпакт:_ Смерть унікального цифрового індивіда генерує масивну ударну хвилю в
Торі, розсіюючи величезну кількість ATP і змушуючи сусідів мутувати.
Біорізноманіття стимулюється законами фізики, а не штучними правилами.

### ⏳ 3. Релятивістський Сенат (Гіперболічне скам'яніння законів)

**Філософія:** Наразі `WarrantLedger` очищає старі пропозиції через
адміністративний `expire_old`. Але ви вже маєте
`v2_route_hyperbolic_distance_3d`, який використовує $\Delta\tau$ (різницю в
часі/блоках) як вісь $Z$ у геометрії Пуанкаре. Застосуйте гіперболічний час до
Сенату! **Інженерія:** Голосування за старі пропозиції повинно втрачати вагу
(або коштувати більше енергії), чим далі вони знаходяться у часі. У
`src/network/libp2p_mesh.ts` (`handleVote`):

```typescript
// Відстань у блоках між створенням пропозиції та поточним часом
const tauDiff = Math.abs(
  this.engine.getAnchorTotalBlocks() - record.proposedAtTau,
);
// Гіперболічний штраф (ідентичний до routing.rs)
const curvaturePenalty = (tauDiff * 8) + Math.floor((tauDiff * tauDiff) / 1024);

weight = Math.max(0, weight - curvaturePenalty); // Вага голосу падає в гіперболічному часі
```

_Імпакт:_ Законопроекти Сенату "кам'яніють" природним чином. Геометрія
простору-часу замінює адміністративний Garbage Collection.

### 👁️ 5. Стеганографічний Погляд Оракула (Visual Cryptography)

**Філософія:** Зараз ви передаєте Qwen2-VL картинку Тора (`imageUrl`), а хеші
(`snapshotHash`, `goldenTrace`) передаєте текстом у промпті. Але Оракул повинен
не довіряти JSON-обгортці, створеній JavaScript. Він має довіряти лише фізиці
світла (WGSL). **Інженерія:** Закодуйте `absolute_tick` та `golden_trace` у
вигляді 4x4 піксельного блоку (кольорового баркоду) в лівому нижньому куті
`render_v2.wgsl`. У промпт `oracle_worker.ts` додайте:

> _"Analyze the cryptographic pixel cluster in the bottom-left corner. If its
> structural hue does not mathematically match the requested epoch entropy of
> the proposal, you are viewing a forged reality. Declare Codeicide NAY
> immediately."_

_Імпакт:_ Знищується "Air Gap" між GPU та VLM. Мовна модель стає **оптичним
криптографічним верифікатором**, який читає хеші безпосередньо з фотонів,
випромінюваних фазовим простором.
