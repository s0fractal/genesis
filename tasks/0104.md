# Task 0104: Era 1180 — Convergence Detection

## Status: COMPLETED | Priority: HIGH

## Context
Era 1170 duplicates high-priority frames along disjoint paths and
deduplicates at the destination. Era 1180 elevates the
"second arrival caught" event into a first-class resilience
signal — proof that the mesh has redundancy headroom AND that the
chosen disjoint paths actually delivered.

## Objective
A destination-side observer that classifies every observed intent
into single-witness / double-witness / triple+ witness, then
exposes aggregate stats that operators can use to quantify the
mesh's effective redundancy.

## Acceptance Criteria

### 1. ConvergenceDetector Module ✅
- [x] `src/network/convergence_detector.ts`:
  - `WitnessRecord { key, first_seen_at_ms, last_seen_at_ms,
    copies, witness_class, frame_type, delivered_by[] }`.
  - `WitnessClass = "single" | "double" | "triple+"`.
  - `observe(frame, delivered_by, now_ms) → WitnessRecord` —
    increment-or-insert.
  - `stats()` → `{total, single, double, triple+, redundancy_rate}`.
  - `proven_carriers()` → spore_ids that participated in ≥1
    multi-witness event.
  - `stragglers(now_ms, stale_ms)` → single-witness intents past
    a staleness threshold (retry candidates).
  - Bounded ring buffer (default capacity 512) with FIFO eviction.

### 2. Behavioral Properties ✅
- [x] Same intent observed twice → witness_class becomes "double".
- [x] Same intent observed thrice → witness_class becomes "triple+".
- [x] Observing the same intent from the same `delivered_by` does
  NOT add to the carrier list (de-double-counts the same deliverer
  reaching us twice).
- [x] `redundancy_rate = double_witness / total_intents` is the
  headline number for HUDs.
- [x] Heartbeats and warrant votes tracked separately (different
  dedup keys).
- [x] Identical intent via different routing metadata (TTL/trail
  legitimately differ) is correctly counted as a duplicate.

### 3. Stragglers / Operator Surface ✅
- [x] `stragglers(now, stale)` returns single-witness intents older
  than `stale` ms — these are candidates for retry / alarm.
- [x] `proven_carriers()` returns sorted unique carrier IDs from
  successful multi-witness deliveries — these are spores the
  operator should trust.

### 4. Tests ✅
- [x] 14 Deno tests cover: first/second/third observation, same
  carrier de-duplication in carrier list, distinct intent tracking,
  stats aggregation (including empty case), proven_carriers
  ordering, stragglers detection, capacity bound eviction, clear,
  invalid capacity validation, heartbeat-and-warrant separation,
  routing-metadata-different-but-intent-same dedup.

## Design Notes
- **Why the carrier list excludes self-duplicates?** If `spore-A`
  forwards a copy that loops back via the same `spore-A`, the
  *delivered_by* hasn't changed — only one carrier proved
  themselves. The carrier list reflects DISTINCT carriers that
  proved their delivery competence.
- **Why is redundancy_rate the headline?** It's the simplest number
  that summarizes "how often does duplication actually pay off"?
  A high rate means the network is redundant; a low rate means
  either we're not duplicating much or secondary paths are
  failing. The operator can then drill down into proven_carriers
  / stragglers for diagnosis.
- **Stragglers fire AFTER stale_ms, not after a single tick.**
  This avoids false-positive alarms during normal jitter — a
  duplicate that takes 200ms longer than the primary is still on
  time. Default operator threshold should be ~5 seconds.
- **Ring buffer bound = 512** keeps memory bounded on relays
  observing busy meshes. At 100 votes/sec, that's a 5-second
  window of intent history — sufficient for resilience analytics.
