Проаналізую OMEGA-64 архітектуру щодо SSoT (Single Source of Truth)
консолідації. Це складна система з розподіленими константами між TypeScript,
Rust та WGSL.

## 🔍 Поточний стан SSoT

З документації видно, що вже існує **`src/ontology/genesis_ssot.ts`** —
центральний генератор констант. Давайте перевіримо, що ще дрейфує.

## 🎯 Що ВАРТО перенести в SSoT (критично для "життя")

### Категорія A: **Еволюційна біологія** (виживання видів)

| Константа                  | Поточне значення | Чому критично                |

## 🎭 Чи потрібні дрейфи для "життя"?

**Коротка відповідь: Ні, але потрібна контрольована варіативність.**

### Що НЕ варто фіксувати (допустимий дрейф):

| Явище                          | Чому дрейф допустимий            |
| ------------------------------ | -------------------------------- |
| `Math.random()` в мутаціях     | Джерело ентропії, не детермінізм |
| `performance.now()` timestamps | Фізичний час зовнішнього світу   |
| User input (semantic intent)   | Емерджентна поведінка            |
| LLM відповіді                  | Недетерміністична креативність   |

### Що ВАРТО фіксувати (SSoT критичний):

| Явище                    | Наслідок дрейфу                              |
| ------------------------ | -------------------------------------------- |
| `SOMATIC_DECAY_RATE`     | Різні середовища = різні види "життя"        |
| `ORACLE_INVOCATION_COST` | Економіка AI зламається                      |
| `MASS_DILATION_*`        | Релятивістська фізика стане непередбачуваною |
| `HODLER_BRAKE_FACTOR`    | ADA не стабілізує систему                    |

## 🚀 План міграції (пріоритети)

1. **P0 (критично)** — Біологічні константи (виживання видів)
2. **P1 (високо)** — ADA термодинаміка (хомеостаз)
3. **P2 (середньо)** — Оракул параметри (AI інтеграція)
4. **P3 (низько)** — Мережеві ліміти (можуть бути runtime-configurable)

## 📝 Підсумок

Система вже має **хорошу архітектуру SSoT** для фізичного шару, але **критичний
дрейф** в біологічній та когнітивній економіці. Це створює ризик, що різні
інстанції OMEGA-64 матимуть різні "закони фізики" для еволюції — що суперечить
ідеї детерміністичного "життя" як математичного об'єкта.

Рекомендую розширити `genesis_ssot.ts` категоріями `BIOLOGY`, `ADA`, `ORACLE` —
це збереже філософську цілісність системи як "біосфери з визначеними законами".
