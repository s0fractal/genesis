# Task 0161: Era 1750 — Translation Policy HUD Telemetry Bridge

## Status

✅ COMPLETED

## Context

Era 1740 exposed translation-policy runtime telemetry as one rich object,
but operator HUD slots are scarce and already overloaded by the V2
kernel. The next safe step was a formatting bridge, not direct DOM
mutation.

## Implementation

- Added `src/network/translation_policy_hud.ts`.
- Introduced `TRANSLATION_POLICY_HUD_SCHEMA = "OMEGA-1750/v1"`.
- Added deterministic HUD band classification:
  - `nominal`
  - `watch`
  - `drift`
  - `blocked`
- Added stable glyph mapping for the four bands.
- Added `formatTranslationPolicyHud(...)`:
  - compact summary line;
  - policy field: local policy hash + drift peer count;
  - peer field: known peers + due peers;
  - warrant field: emitted/failed proposals + corroboration blocks.
- Added `translationPolicyHudFields(...)` helper returning three
  HUD-ready `{label, value}` records.
- Extended `TranslationPolicyInvestigationLoop.summary(...)` to surface
  `local_policy_hash` and `local_pair_count`, already available from
  the underlying monitor summary.

## Tests
