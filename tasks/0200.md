## Мета

Створити standalone public demo OMEGA-64 — інтерактивну візуалізацію lattice,
яку можна розгорнути на GitHub Pages або будь-якому static host.

## Архітектура

```
museum.html          →  Vite entry point
src/bootstrap/museum.ts  →  Boot sequence (no mesh, no ZK, no oracles)
src/lens/v2_renderer.ts  →  Reused unchanged (toroidal mode)
src/environment/v2_bridge.ts → Reused unchanged
```

### Відмінності від production v2.ts

| Feature | v2.ts (production) | museum.ts (demo) |
|---------|-------------------|------------------|
| WebRTC mesh | Libp2pMesh + WebRTCMesh | ❌ None |
| Oracle worker | ✅ Loaded | ❌ None |
| ATP bridge | EthersATPBridge | ❌ None |
| Translation policy | ✅ Full stack | ❌ None |
| Senate interaction | ✅ Live proposals/votes | ❌ Read-only |
| Agent count | ~1M (full) | ~100k (museum scale) |
| Compute mode | V2 (mean-field + DNS) | Toroidal (exact Rust parity) |

## Interaction Design

- **Click / Drag** — inject attractor at mouse position
- **1–4** — preset attractor configurations (Aries, Cancer, Libra, Capricorn)
- **Space** — pause/resume
- **H** — show info panel
- **Export Witness** — download JSON snapshot of current state
