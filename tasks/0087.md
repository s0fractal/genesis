# Task 0087: Era 1010 — Recursive Plasmid Ontology

## Status: OPEN | Priority: HIGH

## Context
Era 1000-1001 foundation is complete:
- `PhaseAddress` with hyperbolic/toroidal distance
- Passive attraction-zone routing in WebRTC mesh
- WGSL GPU-side routing primitives
- JS bridge with WASM FFI and pure-JS fallback

## Objective
Elevate plasmids from simple intent/delta carriers to **semantic payload vessels**
that carry attractor matrices, dipole inverses, LLM oracle injections, and
recursive ontological statements across the P2P mesh.

## Acceptance Criteria

### 1. Plasmid Header Extension
Extend the `V2_SYNC` JSON payload with an optional `plasmid` field:
```typescript
interface PlasmidPayload {
    // PhaseAddress of the attractor this plasmid carries
    attractorAddress: number;
    // 32-bit dipole matrix (attraction + inversion pair)
    matrix: number;
    // Inverse matrix for cleansing/unpacking
    inverse: number;
    // Pulse frequency and amplitude (Q10 fixed-point)
    pulseFreq: number;
    pulseAmp: number;
    // Semantic payload type
    semanticType: 'INTENT' | 'ATTRACTOR' | 'ORACLE_INJECTION' | 'DIPOLE';
    // Recursive nesting: parent plasmid that spawned this one
    parentHash?: number;
    // Depth limit to prevent infinite recursion
    recursionDepth: number;
    maxRecursion: number;
}
```

### 2. Attractor Matrix Validation (Rust)
- [ ] Add `attractor.rs` module in `omega_v2/src/`:
  - `AttractorMatrix { matrix: u32, inverse: u32, pulse_freq: u32, pulse_amp: u32 }`
  - `validate_dipole(m: AttractorMatrix) -> bool`: ensures `matrix XOR inverse == 0xFFFFFFFF`
    (perfect dipole pair — attraction and inversion are bitwise complements).
- [ ] 3 unit tests: valid dipole, invalid dipole, pulse bounds.

### 3. Semantic Consumer in WebRTC Mesh
- [ ] In `webrtc_v2.ts`, when `plasmid` field is present:
  - Validate dipole pair via WASM `v2_validate_dipole`.
  - If `semanticType === 'ATTRACTOR'` and self is closest to `attractorAddress`:
    - Inject attractor into local `SignalStore` (extend `SignalStore` with `attractor_count` and `attractors[4]`).
  - If `semanticType === 'ORACLE_INJECTION'`:
    - Forward to `oracleWorker` for LLM processing.
  - If `recursionDepth >= maxRecursion` — drop (prevent infinite echo).

### 4. GPU Attractor Field
- [ ] Extend `SignalStore` uniform buffer in `compute_v2.wgsl`:
  - Add `attractor_count: u32` and `attractors: array<AttractorMatrix, 4>`.
- [ ] Modify `compute_main`:
  - For each attractor, compute phase drift contribution:
    `drift += sin_q10(agent.phase, attractor.phase) * attractor.pulse_amp / 1024`.
  - This creates "gravity wells" in the phase manifold that pull agents toward attractors.

### 5. Recursive Birth
- [ ] When an agent reaches mitosis threshold near an attractor:
  - Child inherits `parentHash = attractor.matrix`.
  - Child's `genome` is XOR-mutated with attractor pulse pattern.
  - Spawn a "birth announcement" plasmid with `semanticType = 'DIPOLE'`.

## Design Notes
- Keep all new math integer-only (Q10/Q20 fixed-point).
- `AttractorMatrix` fits in 16 bytes — small enough for GPU uniform buffer.
- Dipole validation (`matrix XOR inverse == 0xFFFFFFFF`) is O(1) and deterministic.
- Recursion depth guard prevents plasmid storms in dense meshes.
