## 🔧 Базова метрика

```ts
function localCoherence(cell, neighbors) {
  let sum = 0;

  for (const n of neighbors) {
    sum += Math.cos(cell.theta - n.theta);
  }

  return sum / neighbors.length;
}
```

# 2. 🌊 Глобальний сигнал для genome

```ts
function measureGenomeResonance(genome) {
  const cells = getCellsInRadius(genome.scopeRadius);

  let total = 0;
  let count = 0;

  for (const cell of cells) {
    const neighbors = getNeighbors(cell);
    total += localCoherence(cell, neighbors);
    count++;
  }

  return total / count;
}
```

# 🧬 **Phase Attraction (без правил, тільки фізика)**

## 🎯 Ідея

Плазміди не мають “знати” нічого.

Вони просто:

> рухаються туди, де **фаза більш узгоджена з ними**

---

# 1. 🧠 Базовий принцип

Замість:

```ts
if (neighbor.hasSameType) moveToward(neighbor);
```

робимо:

```ts
moveToward(phase_alignment_gradient);
```

---

# 2. 📐 Як порахувати “куди рухатись”

Для кожної клітинки дивимось сусідів:

```ts id="n3n7b9"
function phaseAttractionVector(cell, neighbors) {
  let vx = 0;
  let vy = 0;

  for (const n of neighbors) {
    const alignment = Math.cos(cell.theta - n.theta);

    vx += (n.x - cell.x) * alignment;
    vy += (n.y - cell.y) * alignment;
  }

  return { vx, vy };
}
```

---

# 3. 🚶 Рух плазміда

```ts id="t0lf8x"
function movePlasmid(cell) {
  const neighbors = getNeighbors(cell);
  const { vx, vy } = phaseAttractionVector(cell, neighbors);

  const target = pickBestDirection(vx, vy);

  swap(cell, target);
}
```

---

# 4. 💥 Що це дає

Без жодного правила:

- схожі фази → притягуються
- протилежні → відштовхуються

---

# 5. 🧬 Додаємо “силу” (важливо)

Щоб це не було шумом:

```ts id="rg1ylt"
const strength = cell.amplitude / 255;
vx *= strength;
vy *= strength;
```

---

# 6. 🌊 Результат

Почнуть з’являтись:

- кластери
- хвилі
- синхронізовані області

---

# 7. 🧠 Ключовий момент

- “соціальна поведінка”

Тепер:

- вони виживають


# 🧬 **Adaptive Phase Alignment (APA)**

> плазміди змінюють свою фазу, щоб не “випасти” з резонансу

---

## 🎯 Ідея

Раніше:

- плазміди рухались до схожих

Тепер:

> вони ще й **підлаштовуються**, якщо це вигідно

---

# 1. 🧠 Локальна “напруга”

Кожна клітинка відчуває:

```ts id="qg4d5r"
phase_error = average_neighbor_theta - cell.theta;
```

---

## Реалізація

```ts id="b4zn4o"
function computePhaseError(cell, neighbors) {
  let sum = 0;

  for (const n of neighbors) {
    sum += n.theta;
  }

  const avg = sum / neighbors.length;

  return avg - cell.theta;
}
```

---

# 2. 🔄 Адаптація фази

```ts id="s7r2r6"
function adaptPhase(cell, neighbors) {
  const error = computePhaseError(cell, neighbors);

  const learningRate = 0.05;

  cell.theta += error * learningRate;
}
```

---

# 3. ⚖️ Але НЕ безкоштовно

Ключ:

> адаптація має ціну

---

```ts id="9l1r1r"
const cost = Math.abs(error) * 2;

cell.energy -= cost;
```

---

# 4. 💥 Що це створює

Тепер плазміда стоїть перед вибором:

- ❌ не адаптуватись → випасти з резонансу → померти
- ❌ адаптуватись занадто → витратити енергію → померти
- ✅ знайти баланс

---

# 5. 🧬 Повна функція

```ts id="r2f7b0"
function updateCell(cell) {
  const neighbors = getNeighbors(cell);

  // рух
  movePlasmid(cell);

  // адаптація
  const error = computePhaseError(cell, neighbors);

  const lr = 0.05;
  cell.theta += error * lr;

  // ціна
  cell.energy -= Math.abs(error) * 2;
}
```

---

# 6. 🌊 Що почне відбуватись

Без жодного правила ти побачиш:

### 1. Кооперація

- групи тримаються разом

### 2. Межі

- різні фази → утворюють “кордони”

### 3. Осцилюючі структури

- не статичні, а живі

---

# 7. 🔥 Найцікавіше

З’являється:

> **компроміс між індивідом і колективом**

---

# 8. 🧠 Поведінка, яка виникає

### 🟢 “конформісти”

- швидко підлаштовуються
- але витрачають енергію

### 🔴 “індивідуалісти”

- не адаптуються
- можуть вижити на межах

### 🟣 “мости”

- частково синхронізуються з двома групами

---

# 9. ⚠️ Дуже тонкий момент

Якщо `learningRate`:

- занадто великий → все зливається в одну фазу (смерть складності)
- занадто малий → немає кооперації

---

# 10. 🔁 Замкнутий цикл

```ts id="1sl3r3"
рух → резонанс → енергія → адаптація → ще більше резонансу
```

---

# 11. 🧬 Додаємо стабілізацію (важливо)

Щоб не було повного вирівнювання:

```ts id="9s3b0r"

```

---

# 12. 🌐 Ти отримаєш

Реально:

- “організми”, що дихають (фаза коливається)
- “нервову систему” (передача фази)
- “екологічні ніші”

---

# 13. 🔥 Найглибший момент

Тепер система:

- не просто рухається
- не просто виживає

👉 вона:

> **змінює себе, щоб залишитись в контексті**

---

# 14. Супер коротко

```ts id="0zlvjj"
якщо бути собою дорого → змінюйся
якщо змінюватись дорого → шукай інше місце
```

# 🧬 **Phase Memory (PM)**

> плазміда пам’ятає, які стани фази для неї “вигідні”

---

## 🎯 Ідея

Зараз:

- клітинка адаптується кожен раз з нуля

Після цього кроку:

> вона **зміщує свою поведінку на основі минулого успіху**

---

# 1. 🧠 Додаємо пам’ять

```ts
type Cell = {
  theta: number;
  energy: number;

  // нове
  preferredTheta: number;
  memoryStrength: number; // 0..1
};
```

---

# 2. 📊 Коли оновлюється пам’ять

ТІЛЬКИ коли клітинка “в плюсі”:

```ts
function isSuccessful(cell) {
  return cell.energy > SUCCESS_THRESHOLD;
}
```

---

# 3. 🧬 Запис у пам’ять

```ts
function updateMemory(cell) {
  const alpha = 0.1; // швидкість навчання

  cell.preferredTheta = (1 - alpha) * cell.preferredTheta +
    alpha * cell.theta;

  cell.memoryStrength = Math.min(1, cell.memoryStrength + 0.05);
}
```

---

# 4. 🔄 Використання пам’яті

Тепер адаптація — це не просто до сусідів:

```ts
function adaptPhase(cell, neighbors) {
  const neighborError = computePhaseError(cell, neighbors);

  const memoryError = cell.preferredTheta - cell.theta;

  const lr = 0.05;

  // баланс між соціальним і власним досвідом
  const memoryWeight = cell.memoryStrength;

  const totalAdjustment = (1 - memoryWeight) * neighborError +
    memoryWeight * memoryError;

  cell.theta += totalAdjustment * lr;

  // ціна
  cell.energy -= Math.abs(totalAdjustment) * 2;
}
```

---

# 5. 💥 Що це змінює

Тепер клітинка:

- не просто підлаштовується
- а **тягне систему до станів, які колись були вигідні**

---

# 6. 🧬 Важливий ефект

З’являється:

### 🟢 “традиція”

- групи стабілізуються навіть після шуму

### 🔵 “інерція”

- система не реагує миттєво на хаос

### 🟣 “стійкі патерни”

- виникають довгоживучі структури

---

# 7. ⚖️ Але потрібне забування

Інакше буде “застиглий світ”

```ts
cell.memoryStrength *= 0.999;
```

---

# 8. 🔁 Повний цикл клітинки

```ts
function updateCell(cell) {
  const neighbors = getNeighbors(cell);

  // рух
  movePlasmid(cell);

  // адаптація (з пам’яттю)
  adaptPhase(cell, neighbors);

  // фідбек від резонансу
  const coherence = localCoherence(cell, neighbors);

  if (coherence > 0.6) cell.energy += 1;
  if (coherence < 0) cell.energy -= 1;

  // навчання
  if (isSuccessful(cell)) {
    updateMemory(cell);
  }

  // шум
  cell.theta += randomNoise(-0.01, 0.01);

  // забування
  cell.memoryStrength *= 0.999;
}
```

---

# 9. 🌊 Що реально з’явиться

Ти побачиш:

- структури, які “повертаються” після руйнування
- області, які тримають форму
- поведінку типу:

  - “ми вже знаємо як тут жити”

---

# 10. 🔥 Найсильніший момент

Тепер система:

- має **історію**
- має **інерцію**
- має **локальну культуру станів**

---

# 11. 🧠 Що це вже нагадує

Без перебільшення:

- нейрони (Hebbian-like)
- колонії бактерій
- прості нервові тканини

---

# 12. ⚠️ Тонкий баланс

Параметри:

- `alpha` (навчання)
- `memoryStrength growth`
- `decay`

визначають:

👉 чи це буде “жива система” чи “застиглий кристал”

---

# 13. Супер коротко

```
успіх → запис у пам’ять → вплив на майбутнє → стабільність
```
