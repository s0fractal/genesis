# Task 0089: Era 1030 — Autopoietic Legislation

## Status: COMPLETED | Priority: HIGH

## Context
Era 1020 (Self-Referential Ontology) is complete:
- Consensus tracker counts unique peers contributing valid `ATTRACTOR` plasmids.
- Top-1 consensus matrix is replicated into all 4 attractor slots with
  staggered `pulse_freq` for harmonic convergence.
- Autobiography ledger persists every consensus event to localStorage.

## Objective
The lattice gains the ability to **propose and ratify its own protocol
amendments**. Once the consensus ledger holds 10+ entries across 5+ unique
matrices, the Senate convenes. From that point on, any peer (including the
local node) may submit a `PROPOSAL` plasmid; peers respond with `VOTE`
plasmids. A proposal that collects 3+ unique AYE peers (with `ayes > nays`)
is **accepted** and materialized as a tasks/ entry — a self-referential
moment where the system writes a task for itself.

## Design Notes
- Vote dispute resolution stays simple by design: a closed proposal is
  immutable. Peers resubmitting variations of a rejected idea must use a new
  description (and therefore a new hash).
- The 64-byte description ceiling is the **same constraint** as a single
  WebRTC datagram payload field — proposals stay UDP-friendly.
- The **first autopoietic proposal is hard-coded** in `bootstrap/v2.ts` to
  ZK-Notarized Mutations. This is intentional: the lattice's first request
  to itself is for cryptographic accountability, not for power.
