## 2. Аналіз підсистем

### 2.1 Цілочисельна математика та LUT (math.rs, topology.rs)

**Оцінка: 9.5 / 10**

- **Xorshift64 + SplitMix64**: Період 2⁶⁴−1, відсутність LCG-артефактів. Використано everywhere — від Big Bang до епігенетичного зміщення.
- **Sine LUT (Q7 + Q10)**: 128- та 256-елементні таблиці з O(1) доступом. Значення в діапазоні [-1024, 1024] для Kuramoto coupling. Бітова маска `& 0xFF` замість `% 256` — zero-cost abstraction.
- **atan2_fast**: CORDIC-подібна реалізація, ~10 операцій, 129-елементний LUT. Є brute-force валідація (`atan2_brute_256`) як референс.
- **Потужності двійки**: Всі розміри топології — power-of-two, що дає zero-cost bitshifts для індексації.

**Проблеми:**
- `atan2_fast` повертає значення 0..255 — дискретизація 8 біт достатня для навігації, але для фізики високої точності може бути обмеженням при q_phase > 7.
- Відсутній формальний proof коректності `sin_q10` vs floating-point `sin` — хоча brute-force тести покривають це емпірично.

### 2.2 Фізичне ядро — tick_physics() (lattice.rs)

**Оцінка: 9.3 / 10**

Kuramoto coupling з фіксованою точкою Q10:
```
coupling = ((sin_left + sin_right) * kuramoto_k) / (2 * q10_scale)
```

- Phase update через `wrapping_add` + `& max_phase` — тороїдальна топологія без branch misprediction.
- Metabolic burn: `base_cost + genome.count_ones() / METABOLIC_BURN_DIVISOR` — популяційна динаміка залежить від Hamming weight геному.
- Resonance replenish при `phase % 64 == 0` — детерміністична "пульсація".

**Проблеми:**
- Лише 1D тороїдальний ланцюг (left/right сусіди). Для 2D/3D решітки потрібна радикальна зміна `PhaseAgentMinimal` та шейдерів.
- `generate_delta_snapshot` позначено `unsafe` — документовано, але формально це порушення чистоти API.

### 2.3 Резонансні поля (resonance.rs)

**Оцінка: 9.0 / 10**

- Global order parameter (Kuramoto r) обчислюється через `i128` акумулятори — запобігання overflow при великих популяціях.
- `u128::isqrt()` (Rust 1.84+) для обчислення норми вектора синхронізації.
- `resonance_score()` — dot-product у Q20-просторі, scaled back до Q10.

**Проблеми:**
- `order_parameter_r_q10()` ділить на `total_energy` — якщо всі агенти мертві (energy=0), це призведе до division by zero. Потрібен guard.
- Resonance field — глобальне середнє поле, немає локальних кластерних параметрів (clustering coefficient, local order parameter).

### 2.4 Топологія та адресація (routing.rs, topology.rs)

**Оцінка: 8.8 / 10**

PhaseAddress: `[consensus:8 | social:8 | personal:8 | micro:8]`
- Hyperbolic distance: `dc*8 + ds*4 + dp*2 + dm` — вагова ієрархія.
- Toroidal wrap: `min(rawDc, 256 - rawDc)` — consensus level обертається.
- Taylor step: clamped per-byte delta — градієнтний спуск у дискретному просторі.
- Greedy routing на 1D торусі доведено працює для q ≤ 7.

**Проблеми:**
- Гіперболічна відстань — лінійна комбінація, а не справжня гіперболічна метрика (cosine law на Poincaré disk). Це евристика, а не формальна геометрія.
- Немає proof convergence для greedy routing при наявності churn (peer join/leave).

### 2.5 ZK-інтеграція (mitosis_proof.rs, pouw.rs)

**Оцінка: 8.0 / 10**

`derive_mitosis_child()` — чиста функція, bit-for-bit reproducible. Три місця виконання:
1. Host Rust
2. SP1 ZK-VM guest
3. JS verification

`child_receipt_hash()` — FNV-1a над 32-байтовим LE серіалізацією дитини.

PoUW (`pouw.rs`) — симуляція агента N циклів з тими ж metabolic rules, що й GPU shader.

**Проблеми:**
- **omega_zk_guest не має жодного тесту** — компілюється в CI, але не запускається.
- `pouw.rs` має лише 6 тестів, немає stress test для >10k циклів.
- ZK handshake у WebRTC (`webrtc_mesh.ts`) — literal mock strings. Будь-хто може інжектувати OFFER/ANSWER.
- SP1 prover не інтегрований end-to-end у продакшн-потік.

### 2.6 Детермінізм — cross-substrate parity

**Оцінка: 9.7 / 10**

Це найсильніша сторона проєкту:
- Rust ↔ WGSL ↔ TS ↔ SP1 — golden traces мають збігатися bit-for-bit.
- Locked anchors (`0x9299_32B5`, `0x843F_5862`, `0x549A6307`) — pinned у всіх тестових наборах.
- `compute_toroidal.wgsl` явно документований як "Exact WGSL port of Rust tick_physics()".
- 283 Rust tests + 842 TS tests + 419 translation_policy tests = ~1564 тести, майже всі проходять.

**Проблеми:**
- WGSL шейдери **не мають автоматизованих тестів** — parity перевіряється лише вручну через locked anchors.
- Немає continuous fuzzing для FFI boundary.

## 5. Висновок

OMEGA-64 має **екстраординарно сильну математичну основу**. Integer-only детермінізм, cross-substrate locked anchors, та Q-fixed-point фізика — це рівень, який рідко зустрічається навіть в академічних симуляторах. Основні слабкості — не в математиці, а в її верифікації (відсутні WGSL тести, ZK guest не тестується, немає formal methods).
