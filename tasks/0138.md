# Task 0138: Era 1520 — Event-Chain Quorum

## Status: COMPLETED | Priority: HIGH

## Context
The forensic event protocol gets all peers to identical
`event_chain_anchor` values after enough sync rounds. But during
convergence (and after partition) peers disagree. Era 1520 makes
that disagreement observable with a pure tracker that consumes
peer anchor claims and reports consensus + dissenters.

## Objective
1. `EventChainQuorumTracker` class with TTL-bounded
   observation storage.
2. `snapshot(now_ms)` returns consensus_anchor, count,
   total_observers, band, dissenter_peer_ids, distinct_anchors,
   agreement_q16.
3. Confidence bands `none/lone/double/triple+/high` mirroring
   Era 1220.
4. `quorumGlyph` HUD helper.

## Design Notes
- **Why `null` for empty consensus?** A numeric consensus value
  for "no observers" would be misleading. `null` is the
  unambiguous "nothing claimed yet" signal — caller handles it
  explicitly. Future Eras (e.g. auto-investigation) gate on
  `consensus_anchor != null` before acting.
- **Why lower-anchor tiebreak?** Tied counts are rare but real
  during early convergence. Deterministic tiebreak ensures two
  operators with identical observation streams compute identical
  consensus — no race conditions, no flapping.
- **Why TTL eviction on read instead of a separate "tick"?**
  No internal clock, eviction needs `now_ms`. Doing it on access
  guarantees every read sees a freshly-pruned state. Cost is
  negligible at typical mesh sizes (tens of peers).
- **Why mirror Era 1220's bands instead of inventing new ones?**
  Operator familiarity. Era 1220 operators already know what
  "double" and "triple+" mean. Reusing the same vocabulary makes
  multi-Era telemetry reads straightforward.
- **Why is `high_threshold` configurable?** Different mesh sizes
  warrant different thresholds. A 5-peer mesh's "triple+" is
  different from a 100-peer mesh's. Operators tune to their
  deployment.
- **Why does re-observe always overwrite, even with stale
  timestamps?** Trust the most recent observation. A peer
  reporting a "rolled back" anchor is suspicious behavior to
  flag separately (Era 1220's investigation handles that),
  not data the quorum tracker should preserve.
