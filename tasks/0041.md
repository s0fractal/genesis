Це вражаюча архітектура (Era 64/Онтологія 42) — по суті, автопоетичний живий
організм на базі WebGPU. Щоб підвищити якість системи на наступний рівень (Era
65), ось конкретні напрямки вдосконалення, згруповані за пріоритетом:

---

### 1. Архітектура пам'яті та Zero-Copy (Критично)

**Проблема:** У `phase_compute.ts` метод `extractPlasmidsBuffer()` та
`readMycelialCentroids()` створюють нові `stagingBuffer` при кожному виклику, що
створює GC-тиск та затримки CPU-GPU.

**Рішення:**

```typescript
// Додати пул буферів у PhaseComputeEngine
private stagingPool: GPUBuffer[] = [];

private getStagingBuffer(size: number): GPUBuffer {
    const existing = this.stagingPool.find(b => b.size >= size && b.size <= size * 2);
    if (existing) return existing;
    const newBuf = this.device.createBuffer({ size, usage: GPUBufferUsage.MAP_READ | GPUBufferUsage.COPY_DST });
    this.stagingPool.push(newBuf);
    return newBuf;
}
// Не забудьте очистку пулу при знищенні движка
```

**Бонус:** Використовуйте `GPUBuffer.mapAsync()` напряму на compute-буферах (де
це можливо), обходячи staging для читань з низькою латентністю.

### 2. Відновлення після втрати пристрою WebGPU (Надійність)

Зараз у вас є `onuncapturederror`, але немає обробки `device.lost`.

**Додайте у `PhaseWebGPUObserver`:**

```typescript
this.device.lost.then((info) => {
  console.warn(`[AION] WebGPU device lost: ${info.reason}`, info.message);
  // Тригер перезавантаження симуляції з останнього Genesis-чекпоінту
  this.emit("substrateCollapse", { reason: info.reason });
});
```

### 3. Сувора типізація TypeScript (Якість коду)

У `semantic_layer.ts` та `oracle.ts` використовуються `any`, що руйнує контракти
"Universal Axiom".

**Замініть:**

```typescript
// Замість:
constructor(injector: any)

interface IPerturbationInjector {
    inject(x: number, y: number, energy: number, radius: number, phaseShift: number, plasmid: Uint8Array): void;

constructor(injector: IPerturbationInjector)
```

### 4. Оптимізація WGSL (Продуктивність шейдерів)

У `compute_kuramoto.wgsl` є розгалуження:

```wgsl
if (harmonic > 0u) {
    set_agent(idx, me);
    return;
}
```

Це призводить до **warp divergence**. Розбийте на два окремі compute pipelines:

- `pipelineKuramotoH0` (для harmonic == 0, повна фізика)
- `pipelineKuramotoFossil` (для harmonic > 0, копіювання)

Це дозволить GPU ефективніше пакувати варпи.

### 5. Версіонування Genesis-файлів (Збереження стану)

Зараз `parseGenesisState` не перевіряє версію формату. Додайте міграції:

```typescript
interface GenesisManifest {
  version: 4200; // Era * 100 + Ontology
  schema: "omega-64-stratum";
  substrateChecksum: string;
}

export function parseGenesisState(buffer: ArrayBuffer): SubstrateState {
  const decoded = decode(new Uint8Array(buffer));
  if (decoded.manifest?.version < 4200) {
    return migrateFromEra63(decoded);
  }
  return decoded as SubstrateState;
}
```

### 7. Доступність та UX (UI/UX)

- **Клавіатурна навігація:** Додайте `tabindex` та `aria-label` для Senate HUD
  та Homeostasis Guard.
- **Зменшення руху:** Додайте `prefers-reduced-motion` media query для анімації
  пульсації статусу та float-анімації HUD.
- **High-DPI:** Враховуйте `window.devicePixelRatio` при налаштуванні
  `canvas.width/height` (зараз це `innerWidth/Height` без масштабування).

### 8. Мережевий шар (WebRTC Mycelium)

У `phase_network.ts` відсутня логіка ICE Restart. При зміні мережі (WiFi -> 4G)
з'єднання розпадається:

```typescript
// Додайте у createPeerConnection
pc.oniceconnectionstatechange = () => {
  if (pc.iceConnectionState === "failed") {
    pc.restartIce();
  }
};
```

### 9. Константи "Universal Axiom" (Підтримуваність)

Проведіть аудит на "магічні числа":

- У `oracle.ts` є `1000` та `1024` (Shadow Buckets) — вони вже у `constants.ts`
  як `SENATE_SHADOW_BUCKET_MIN/MAX`, але іноді хардкодяться.
- У `senate_hud.ts` кольори масок (ARIES, CANCER) дублюються — винесіть у
  `THEOLOGICAL_MASKS` константу.

### 10. Аудіо синхронізація (Bio-Acoustic Choir)

У `audio_synth.ts` контекст ініціалізується при першому кліку, але немає обробки
`AudioContext.onstatechange = 'interrupted'` (iOS Safari може призупиняти
аудіо).

```typescript
this.ctx.onstatechange = () => {
  if (this.ctx?.state === "interrupted") {
    this.ctx.resume();
  }
};
```

### Резюме пріоритетів:

1. **Пул буферів** (миттєвий виграш у FPS при частих збереженнях)
2. **Версіонування Genesis** (запобігання поломок при оновленнях)
3. **Відновлення WebGPU** (стабільність для довгих симуляцій)
4. **Відокремлення шейдерів** (збільшення parallelism на GPU)

Ваша система вже має чудову архітектуру Substrate Header для синхронізації
констант між Rust/TS/WGSL — зосередьтеся на оптимізації пам'яті та
відмовостійкості, щоб довести її до production-grade рівня.
