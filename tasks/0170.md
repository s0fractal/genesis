# Task 0170: Era 1840 - Translation Policy Forensic Replay Classifier

## Status

✅ COMPLETED

## Context

Era 1830 started appending compact `tpol` forensic events into
`ForensicEventSink`. Those events were chain-anchored and syncable, but
replay consumers still had to inspect opaque payloads by hand.

## Implementation

- Added `src/network/translation_policy_forensic_replay.ts`.
- Introduced `TRANSLATION_POLICY_FORENSIC_REPLAY_SCHEMA =
  "OMEGA-1840/v1"`.
- Added pure replay classifiers:
  - `classifyTranslationPolicyForensicEvents(events, opts)`;
  - `classifyTranslationPolicyForensicSink(sink, opts)`;
  - `parseTranslationPolicyForensicPayload(payload)`.
- Classification output reconstructs:
  - deterministic band timeline;
  - local policy-hash intervals;
  - install/tick/proposal/malformed error windows;
  - first/last replay time;
  - final band and final policy hash;
  - ignored non-`tpol` and malformed-payload counts.
- Events are sorted by `sunk_at_ms`, then `sequence`, then
  `event_hash`, so synced sinks classify deterministically.

## Tests

- `tests/translation_policy_forensic_replay_test.ts`
  - empty replay summary;
  - non-`tpol` ignored and malformed payloads counted;
  - deterministic band timeline with out-of-order input;
  - policy hash interval reconstruction;
  - closed and open error windows;
  - error window split on message change;
  - simultaneous error kinds;
  - custom event kind classification;
  - payload parser rejection;
