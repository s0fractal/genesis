# Task 0109: Era 1230 — Reputation Feedback from Convergence

## Status: COMPLETED | Priority: HIGH

## Context
Era 1140 scored neighbors from observable transport behavior.
Era 1220 surfaced consensus suspicion (corroboration_count ≥
threshold) as a soft signal. Era 1230 connects the two: targets
flagged by ≥2 distinct relay alarms get a soft reputation penalty
applied during routing decisions, BEFORE the Senate's hard gate
(Era 1090's 3 AYE oracles) ratifies a quarantine.

## Objective
Provide pure functions that compute deterministic soft penalties
from `CorroboratedRecord` data and apply them to
`ReputationScore[]` arrays, leaving the original scores
untouched. Two relays observing the same convergence + scoring
history produce byte-identical penalty maps.

- [x] `max_diff_q16` contributes `(max_diff/1024) × 5`, capped at

- [x] Score never goes below 0 (`Math.max(0, ...)`).

## Design Notes
- **Why penalty starts at trigger_floor=2?** A single-relay alarm
  could be a local glitch (radio interference, brief reboot). The
  reputation layer shouldn't react to noise. Two distinct alarms
  on the same proposal_hash is the first point where we have
  cross-observer agreement.
- **Why is max_penalty=100 below the typical score range?** A
  relay with a perfect score (~250) gets reduced to ~150 — losing
  top rank but still eligible. Hard exclusion stays Codeicide's
  job. The soft layer's purpose is **reorder routing**, not
  **terminate participation**.
- **Why does max_diff_q16 contribute?** A "large diff" alarm
  (e.g. 65536 = 100% disagreement) is more alarming than a
  "barely past threshold" one (6553 = 10%). Folding diff magnitude
  into the penalty makes the scoring track the alarm's severity,
  not just its existence.
- **Why pick highest-corroboration-record per target?** When N
  distinct partition observations stream in for the same relay,
  the most corroborated one is the most credible signal. Aggregating
  (e.g. summing penalties from multiple records) would let an
  attacker spam alarms to manufacture penalties; using max ensures
  a single high-quality observation is never amplified.
