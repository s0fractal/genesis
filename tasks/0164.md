# Task 0164: Era 1780 - Translation Policy Mesh Emit Adapter

## Status

✅ COMPLETED

## Context

Era 1770 introduced a runtime factory, but it deliberately accepted
narrow emit callbacks instead of importing `WebRTCV2Mesh`. The missing
piece was a small adapter that turns the live mesh's `enqueuePlasmid`
surface into those callbacks.

## Implementation

- Added `src/network/translation_policy_mesh_emit_adapter.ts`.
- Introduced `TRANSLATION_POLICY_MESH_EMIT_ADAPTER_SCHEMA =
  "OMEGA-1780/v1"`.
- Added `TranslationPolicyMeshEmitAdapter` over any mesh-like object
  exposing `enqueuePlasmid(plasmid)`.
- Added callback bundle compatible with Era 1770:
  - `claim_emit`;
  - `raise_emit`;
  - `warrant_emit`.
- Added direct plasmid builders:
  - `translationPolicyClaimPlasmid(...)`;
  - `translationPolicyCorroborationPlasmid(...)`;
  - `translationPolicyWarrantPlasmid(...)`.
- Added deterministic default dipole template with complement inverse.
- Added telemetry for sent/failed claim, raise, and warrant enqueue
  attempts.

## Tests

- `tests/translation_policy_mesh_emit_adapter_test.ts`
  - claim plasmid emission;
  - corroboration-raise plasmid emission;
  - Senate-compatible policy warrant proposal emission;
  - callback compatibility with the Era 1770 factory;
  - telemetry for success/failure;
  - custom matrix complement derivation;
  - direct plasmid helper field preservation;
  - invalid dipole / recursion rejection;
  - schema constant.

## Invariant Notes

- Adapter depends only on a mesh-like `enqueuePlasmid` contract.
- `WebRTCV2Mesh` itself remains unchanged.
- Policy warrants are emitted as standard `PROPOSAL` plasmids with the
  existing senate-compatible hash/description pair.
- Dipole invariant is enforced before adapter use.
