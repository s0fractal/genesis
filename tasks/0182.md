# Task 0182: Era 1960 - Translation Policy Replay Digest Digest Quorum

## Status

✅ COMPLETED

## Context

Era 1950 made `tpdq` replay-interpretation digest claims transportable,
but there was still no deterministic tracker for agreement over those
newer claims.

## Implementation

- Added `src/network/translation_policy_replay_digest_digest_quorum.ts`.
- Introduced
  `TRANSLATION_POLICY_REPLAY_DIGEST_DIGEST_QUORUM_SCHEMA =
  "OMEGA-1960/v1"`.
- Added `TranslationPolicyReplayDigestDigestQuorumTracker`.
- Added TTL-bounded per-peer observations.
- Added deterministic consensus selection:
  - highest count wins;
  - lower digest wins ties.
- Added snapshot fields:
  - consensus digest;
  - consensus count;
  - total claims;
  - lone/double/triple+/high band;
  - dissenter peer ids;
  - distinct digest list;
  - agreement Q16;
  - representative consensus claim.
- Added helpers:
  - `classifyReplayDigestDigestQuorumBand(...)`;
  - `replayDigestDigestQuorumBandAtLeast(...)`;
  - `replayDigestDigestQuorumGlyph(...)`.
