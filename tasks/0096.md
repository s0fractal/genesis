# Task 0096: Era 1100 — Bare-Metal Spores

## Status: COMPLETED | Priority: HIGH

## Context
Eras 1010 → 1090 demonstrated determinism across three substrates:
- Desktop host (`aarch64-apple-darwin`, `cargo test`)
- Browser/WASM (`wasm32-unknown-unknown`, Deno tests + Vite)
- SP1 ZK guest (`riscv64im-succinct-zkvm-elf`, real STARK proofs)

Era 1100 closes the **fourth** substrate: actual microcontroller silicon.
The same FNV-1a polynomials, the same integer-only mitosis derivation,
the same Senate quorum hashing — running on ARM Cortex-M4F hardware
emulated in QEMU.

## Objective
Compile and boot `omega_v2` cross-language anchors on
`thumbv7em-none-eabihf` with byte-equivalent FNV-1a output. The win
condition: a Cortex-M4 board (or QEMU-emulated equivalent) executes
`validate_anchors()` against all 11 v1.0 anchors and enters its
reactor loop without trapping.

## Acceptance Criteria

### 1. omega_v2 cross-compile cleanliness ✅
- [x] Extended the no_std cfg gate from `wasm32`-only to
  `any(wasm32, target_os = "none")`. ARM Cortex-M's `target_os` is
  `none`, so the gate now activates for both browser and bare-metal.
- [x] Made the panic_handler optional via `builtin-panic` Cargo
  feature (default-on). Bare-metal binaries opt out via
  `default-features = false` to supply their own.
- [x] Quad-target compile: host + wasm32 + thumbv7em + riscv64
  zk-vm all build cleanly with the same source.

### 2. omega_spore bare-metal binary ✅
- [x] Standalone crate at `omega_spore/` (workspace = []).
- [x] Validates 11 canonical OMEGA-64 v1.0 anchors at boot:
  senate_hash_empty, senate_hash_short, mitosis_receipt_no_attr,
  GENESIS_HASH_V1_0, five oracle dipoles, codeicide quorum, codeicide
  warrant.
- [x] Halts in panic_handler on any drift; enters reactor loop
  (single ARM `nop` instruction) on success.
- [x] Hand-rolled minimal Cortex-M vector table (initial MSP +
  reset handler) — no `cortex-m-rt` dep needed for the smoke build.
- [x] Custom `memory.x` linker script targets QEMU's `mps2-an386`
  4 MB SRAM @ 0x21000000.
- [x] 6 KB stripped ELF, statically linked, no libc.

### 3. QEMU smoke run ✅
```bash
qemu-system-arm \
    -cpu cortex-m4 \
    -machine mps2-an386 \
    -nographic \
    -semihosting \
    -kernel target/thumbv7em-none-eabihf/release/omega_spore
```
- [x] Boots without HardFault.
- [x] No exit during the validation window — implies all 11 anchors
  reproduced bit-for-bit on the emulated Cortex-M4F core.

### 4. Host-side example ✅
- [x] `omega_v2/examples/spore_smoke.rs` runs the same anchor
  battery on the host with stdout output. Useful for sanity-checking
  the desktop build before flashing.

## Design Notes
- **Why not `cortex-m-rt`?** The standard runtime crate provides
  `#[entry]`, exception handlers, and a default linker script. For
  Era 1100's smoke goal — *prove the math works on Cortex-M4F* —
  pulling in `cortex-m-rt` would obscure the minimal proof. The
  hand-rolled vector table fits in 16 lines and demonstrates that
  no_std compatibility is genuine, not framework-dependent.
- **Why a separate workspace?** Bare-metal builds need different
  default targets, panic strategies, and linker flags. Adding
  `omega_spore` to the root workspace would force every `cargo
  build --workspace` to also try cross-compiling, which fails on
  hosts without `thumbv7em-none-eabihf` installed.
- **Why mps2-an386?** It's QEMU's standard Cortex-M4 reference
  platform with simple SRAM-only memory map (no flash controller,
  no peripherals to initialize). For a smoke build that doesn't
  touch hardware, this is ideal.
