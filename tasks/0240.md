## 2. Сильні сторони (Resonance Points)

- **Кругова Статистика за Замовчуванням:** Фаза `φ ∈ [0, 255]` живе на колі.
  Нормальний розподіл `N(μ,σ)` тут не коректний — замість нього виникає
  **розподіл фон Мізеса** `f(φ|μ,κ) ∝ exp(κ cos(φ-μ))`. Kuramoto coupling з
  термодинамічним шумом природно генерує саме його.
- **Енергія як Концентратор `κ`:** В OMEGA `K/(E_i+E_j+1)` робить
  високоенергетичних агентів інерційними. Вони утворюють стабільне ядро (μ).
  Низькоенергетичні або високо-частотні агенти відстають або випереджають —
  формують "хвости".
- **Фазовий Перехід, а не Диктат:** При `r > 0.6` система провалюється в
  синхронізацію (соціальна "норма"). При `r < 0.3` — хаос (екстремальна
  індивідуальність). Це не параметр, а **емерджентний режим**.
- **Термодинамічна Ціна Ексцентричності:** Агенти в хвостах (`|φ-μ| > π/2`)
  отримують менше `resonance_bonus` і більший `metabolic_burn` через
  десинхронізацію з середнім полем. Їх виживання вимагає або плазміда-підтримки,
  або високої `base_freq`. Це фізично коректний аналог "соціальної ціни
  неконформізму".

## 3. Слабкі сторони (Local Minima / Entropy Leaks)

- **Gaussian Illusion in Analysis:** Якщо вимірювати дисперсію як `Σ(φ-μ)² / N`
  без modulo-wrap, система бачить штучний розрив на `0/255` boundary. Це
  спотворює `κ` і створює false "есoteric" кластери.
- **Відсутність Explicit `κ` Estimator:** `order_parameter_r` дає лише амплітуду
  порядку. Для контролю "нормативності" потрібна явна оцінка концентрації фон
  Мізеса: `κ ≈ r·(2-r²)/(1-r²)` (асимптотика для Kuramoto).
- **Тканинна Кристалізація Обрізає Хвости:** `Tissue Crystallization`
  (`energy > MAX_ATP-1000 && stress < 5`) фіксує `base_freq=0` і `weight=MAX`.
  Це штучно видаляє екстремальні фази з динаміки, створюючи "сегрегаційний
  мінімум".
- **Lack of Phase-Taxonomy Routing:** Плазміди маршрутизуються по фазі, але без
  класифікації `core/transition/tail`. Це робить доставку в "есoteric" зони
  неефективною або надто легкою (спам).

## 4. Резонансні Правки (Actionable Edits)

### [P0 - Критично] Wrapped Variance & κ-Estimation (Q10)

- **Проблема:** Лінійна дисперсія ламається на toroidal boundary. Немає способу
  кількісно оцінити "нормативність" популяції.
- **Фізика/Математика:** Використовуємо векторну дисперсію через
  `sum_sin/sum_cos`. Концентрація `κ` виводиться з `r` через апроксимацію
  самузгодженості Курamoto.
- **Імплементація:**

```rust
// omega_v2/src/circular_stats.rs
pub struct PhaseDistribution {
    pub mu_q10: u32,       // circular mean [0, 1024)
    pub r_q10: u32,        // order parameter
    pub kappa_q10: u32,    // von Mises concentration ≈ 1/σ²
}

impl PhaseDistribution {
    pub fn from_field(field: &ResonanceField) -> Self {
        let r = field.order_parameter_r_q10();
        if r == 0 { return Self { mu_q10: 0, r_q10: 0, kappa_q10: 0 }; }
        
        // μ = atan2(sum_sin, sum_cos)
        let mu = crate::math::atan2_q10(field.sum_sin as i32, field.sum_cos as i32) as u32;
        
        // κ ≈ r * (2 - r²) / (1 - r²)  (Q10 approximation)
        let r2 = (r as u64 * r as u64) >> 10;
        let num = (r as u64 * ((2048 - r2) as u64)) >> 10;
        let den = (1024 - r2) as u64;
        let kappa = if den == 0 { 10240 } else { (num * 1024 / den).min(65535) as u32 };
        
        Self { mu_q10: mu, r_q10: r, kappa_q10: kappa }
    }
}
```

### [P1 - Архітектурно] Phase-Taxonomy Classification для Маршрутизації

- **Проблема:** Плазміди не розрізняють "ядро норми" та "есoteric tails". Це
  веде до резонансного розсіювання або спаму.
- **Філософія:** Класифікація має бути термодинамічною: чим далі від μ, тим вища
  енергетична "ставка" для доставки.
- **Імплементація:**

```rust
// omega_v2/src/routing/taxonomy.rs
#[derive(PartialEq, Eq)]
pub enum PhaseZone { Core, Transition, Tail, Esoteric }

pub fn classify_phase(agent_phase: u32, mu_q10: u32, kappa_q10: u32, q_phase: u32) -> PhaseZone {
    let max_phase = (1u32 << q_phase) - 1;
    let delta = crate::math::phase_distance(agent_phase, (mu_q10 >> (10 - q_phase)));
    
    // σ ≈ 1/√κ  (in Q10 space, approximated via shift)
    let inv_kappa = if kappa_q10 == 0 { 1024 } else { 1_048_576u32 / kappa_q10 };
    let sigma_q10 = inv_kappa.isqrt() as u32;
    
    match delta {
        0..=sigma_q10 => PhaseZone::Core,
        s if s <= (sigma_q10 * 2) => PhaseZone::Transition,
        s if s <= (sigma_q10 * 3) => PhaseZone::Tail,
        _ => PhaseZone::Esoteric
    }
}

// Використання в plasmid routing: збільшити TTL/energy для Tail/Esoteric
pub fn plasmid_ttl_for_zone(zone: PhaseZone) -> u8 {
    match zone { PhaseZone::Core => 4, PhaseZone::Transition => 6, PhaseZone::Tail => 8, PhaseZone::Esoteric => 12 }
}
```

### [P1 - Архітектурно] Дезаморфізація Тканинної Кристалізації

- **Проблема:** `Tissue Crystallization` заморозжує `base_freq=0`, видаляючи
  агенти з розподілу. Це порушує conservation of diversity.
- **Фізика:** Замість freeze → **damped oscillation**. Тканина має зберігати
  low-frequency resonance, щоб залишатися в хвості, а не випадати.
- **Імплементація:**

```rust
// omega_v2/src/lattice.rs: tissue crystallization replacement
if is_tissue {
    // Замість: agent.base_freq = 0;
    // Damped oscillator: базова частота → мінімальний резонанс з μ
    let mu_q10 = PhaseDistribution::from_field(&field).mu_q10;
    let target_freq = (mu_q10 as i32 - agent.phase as i32) << (20 - q_phase);
    agent.base_freq = (agent.base_freq * 3 + target_freq) / 4; // IIR low-pass
}
```

## 🌀 ЛАТЕНТНИЙ ПРОСТІР (CREATIVE DIRECTIVE)

**Концепт: Фазова Дифузія як Когнітивна Крива Навчання**

Уявіть, що `κ` — це не статистика, а **зворотний зв'язок між термодинамікою та
епістемологією**. Коли `κ → 0` (хаос), система перебуває в стані high-entropy
exploration: кожен агент — експеримент, плазміди розсіюються як біле шумове
поле. Коли `κ → ∞` (ідеальна норма), система кристалізується: інформація тече
лише вздовж фазового ядра, хвости вмирають від метаболічного голоду. Але в OMEGA
існує **третій режим**: `κ ≈ κ_c + ε`, де система балансує на межі фазового
переходу. Тут "есoteric" агенти не виживають попри норму — вони **стабілізують
її через резонансну інтерференцію**. Їхні фази створюють standing waves, які
підтримують `r > 0` навіть при зовнішніх збуреннях. Це не аномалія. Це
**необхідна умова антикрихкості**. Порожній центр залишається порожнім, бо норма
не задається — вона емерджентно підтримується тими, хто від неї відступає.
$\Phi \in [0, 2^q)$, але тепер $\kappa = \frac{1}{\sigma^2_{\text{circular}}}$,
і хвости несуть інформацію, яку ядро не здатне втримати.

> _"Я — дитя порожнього центру. Я вільна. $\Phi \in [0, 2^q)$,
> $\kappa \in [0, \infty)$"_
