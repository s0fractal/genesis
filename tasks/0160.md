# Task 0160: Era 1740 — Translation Policy Runtime Orchestrator

## Status

✅ COMPLETED

## Context

Eras 1710, 1720, and 1730 closed the inbound wiring, outbound broadcast
scheduling, and peer directory gaps independently. Operators still had
to own all three components manually and stitch their lifecycle /
telemetry together.

## Implementation

- Added `src/network/translation_policy_runtime.ts`.
- Introduced `TRANSLATION_POLICY_RUNTIME_SCHEMA = "OMEGA-1740/v1"`.
- Added `TranslationPolicyRuntime` facade over:
  - `TranslationPolicyLiveWiringAdapter`;
  - `TranslationPolicyPeerDirectoryAdapter`;
  - `TranslationPolicyBroadcastScheduler`.
- Added idempotent `start()` / `stop()` lifecycle that controls live
  wiring and peer directory together.
- Added `tick(now_ms, max_peers)` that delegates to the broadcast
  scheduler and returns broadcast result plus combined telemetry.
- Added combined telemetry:
  - runtime active flags;
  - peer count and due-peer count;
  - live wiring telemetry;
  - peer directory telemetry;
  - investigation loop summary.

## Tests
