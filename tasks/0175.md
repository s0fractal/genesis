# Task 0175: Era 1890 - Translation Policy Replay Digest Live Wiring

## Status

✅ COMPLETED

## Context

Era 1880 can classify replay-digest claims, but those claims still had
to be manually decoded and inserted into the quorum tracker.

## Implementation

- Added `src/network/translation_policy_replay_digest_live_wiring.ts`.
- Introduced `TRANSLATION_POLICY_REPLAY_DIGEST_LIVE_WIRING_SCHEMA =
  "OMEGA-1890/v1"`.
- Added `TranslationPolicyReplayDigestLiveWiringAdapter`:
  - subscribes to `translationPolicyReplayDigestClaim` by default;
  - supports custom event names;
  - decodes Era 1870 claim bodies;
  - feeds Era 1880 quorum tracker;
  - exposes start/stop/idempotent lifecycle;
  - tracks received/malformed/observed counters;
  - exposes `snapshot(...)` as a tracker proxy.
- Added explicit local emission helper:
  - `emitLocalClaim(target_peer_id, digest?, now_ms?)`;
  - optional digest provider;
  - local peer/witness ids;
  - emit/success/failure/skip telemetry.
