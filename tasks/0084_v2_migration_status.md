# 🚀 OMEGA-64: V2 Migration Status (omega_next)

Цей документ фіксує прогрес розгалуження (Side-by-Side) Ери 920-960. Ми не ламаємо `v42.1.0`, натомість будуємо ідеально вирівняний, `no_std` фундамент паралельно.

## ✅ Виконано сьогодні (Era 920-960 кістяк):

1. **Bare-Metal Substrate (`omega_v2` Crate):**
   - Створено паралельний Rust-крейт `#![no_std]`.
   - Встановлено жорсткий профіль: `panic = "abort"` на весь workspace для нульових оверхедних абстракцій.

2. **Phase Topology (Математика $Q$-степенів):**
   - Реалізовано `PhaseTopology` (`omega_v2/src/topology.rs`), де всі розмірності сітки — це чисто експоненти (напр. $Q = 7 \rightarrow 128$).
   - Всі обчислення індексів секторів та переповнення кутів зведені до безкоштовних **бітових зсувів (`>>`)** і масок. Жодного повільного ділення.

3. **Variable Agent Structure (SIMD Вирівнювання):**
   - Оголошено `PhaseAgentMinimal` (точно **16 байт**, ідеально для GPU `vec4<u32>`).
   - Оголошено `PhaseAgentSmart` (точно **32 байти**, для майбутніх ортогональних станів і пам'яті атракторів).
   - *Чому це важливо:* Це дозволить WGSL читати пам'ять без дефрагментації (Coalesced Memory Access).

4. **TS Hardware Constraints (`environmental_vector.ts`):**
   - Написано алгоритм, який отримує реальний VRAM ліміт WebGPU (наприклад, 128 МБ).
   - Обчислює 80% Дарвінівського ліміту пам'яті.
   - Динамічно (Gradient Search) нарощує розміри сітки (sectors, radial, harmonics) до максимальних $2^n$ значень, які влізуть у цей ліміт. "Клімат" комп'ютера обчислюється автоматично.

5. **Reactive SignalStore (Dirty Flags замість Allocations):**
   - Створено `omega_v2/src/lattice.rs`.
   - Написано архітектуру, де оновлення середовища від JS лише піднімає 1 біт у `dirty_flags` (наприклад, `SIGNAL_TOPOLOGY_CHANGED`).
   - Фізичний луп автоматично розпізнає це і проводить *Darwinian Cull* (видаляє слабкі сутності), запобігаючи витокам пам'яті та реаллокаціям.

6. **WGSL V2 Boilerplate (`compute_v2.wgsl`):**
   - Створено новий паралельний compute-шейдер.
   - Оголошено ту саму 16-байтну структуру `PhaseAgentMinimal` для прямого `SharedArrayBuffer` мапінгу до пам'яті Rust.
   - Рендер зможе читати змінні константи прямо з Уніформ-буферів.

## 🔜 Наступні Кроки (Що обрати далі?):

* **[Вектор A] Інфраструктура (build_v2.ts):** Написати Deno скрипт компіляції, який буде передавати флаги заліза прямо в аргументи Cargo під час збірки (AOT).
* **[Вектор B] WGSL Pipeline:** Підключити новий `compute_v2.wgsl` і `omega_v2.wasm` до базової WebGL/WebGPU стцени, щоб візуалізувати цю 16-байтну пам'ять (перехід від `v42` до `v2`).
* **[Вектор C] LERP Interpolation у Rust:** Дати Rust можливість плавно асимптотично змінювати константи при піднятті `dirty_flags`.
