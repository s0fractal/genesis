# Task 0162: Era 1760 - Translation Policy Bootstrap Hook

## Status

✅ COMPLETED

## Context

Era 1750 produced a pure HUD formatter for translation-policy runtime
telemetry. Bootstrap still had no safe way to surface that telemetry in
the live V2 HUD without expanding the DOM contract or overwriting core
kernel telemetry unconditionally.

## Implementation

- Added `src/bootstrap/translation_policy_hud_hook.ts`.
- Introduced `TRANSLATION_POLICY_HUD_HOOK_SCHEMA = "OMEGA-1760/v1"`.
- Added `TranslationPolicyHudHook`, a small opt-in adapter that:
  - reads telemetry from any runtime-like source exposing
    `telemetry(now_ms)`;
  - formats it through Era 1750's `formatTranslationPolicyHud`;
  - writes one existing HUD slot through the existing `setHudStat`
    contract;
  - throttles writes with `min_interval_ms`;
  - contains runtime exceptions without poisoning the render loop.
- Added `createTranslationPolicyHudHook(...)` factory.
- Added `mergeTranslationPolicyHudHookOptions(...)` with nested partial
  HUD option support.
- Wired `src/bootstrap/v2.ts` to discover optional globals:
  - `window.__OMEGA_TRANSLATION_POLICY_RUNTIME__`
  - `window.__OMEGA_TRANSLATION_POLICY_HUD__`
- Default behavior remains inert. The hook writes only when the runtime
  exists and HUD opt-in is explicitly enabled.

## Tests

- `tests/translation_policy_hud_hook_test.ts`
  - default disabled behavior;
  - enabled HUD write to a configured slot;
  - deterministic interval throttling;
  - runtime exception containment;
  - null-source factory inertness;
  - nested partial option merge;
  - schema constant.
