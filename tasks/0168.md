# Task 0168: Era 1820 - Translation Policy Snapshot Event Emission

## Status

✅ COMPLETED

## Context

Era 1810 stabilized
`window.__OMEGA_TRANSLATION_POLICY_TELEMETRY__`, but diagnostics consumers
still had to poll a frame-loop global. Operators and future forensic
sinks need a narrow subscription point that does not own runtime cadence,
DOM slots, or network IO.

## Implementation

- Added `src/bootstrap/translation_policy_telemetry_event.ts`.
- Introduced `TRANSLATION_POLICY_TELEMETRY_EVENT_SCHEMA =
  "OMEGA-1820/v1"`.
- Added `TranslationPolicyTelemetryEventEmitter` with:
  - opt-in `enabled` defaulting to `false`;
  - bounded `min_interval_ms` throttle;
  - deterministic FNV-1a change hash over stable telemetry fields;
  - wall-clock churn ignored for change detection;
  - configurable event name, defaulting to `translationPolicyTelemetry`;
  - dispatch-error containment.
- Extended `TranslationPolicyBootstrapInstallOptions` with
  `telemetry_event?: boolean | options`.
- Installer now publishes
  `window.__OMEGA_TRANSLATION_POLICY_TELEMETRY_EVENT__` for opt-in
  bootstrap configurations, defaulting to `false`.
- Wired `src/bootstrap/v2.ts` to emit telemetry events after publishing
  the Era 1810 snapshot.

## Tests

- `tests/translation_policy_telemetry_event_test.ts`
  - disabled emitter is inert;
  - first enabled tick dispatches a `CustomEvent`;
  - cooldown throttles dispatch;
  - unchanged snapshots are suppressed after cooldown;
  - changed snapshots emit after cooldown;
  - custom event names work;
  - `emit_on_change_only:false` allows refresh events;
  - dispatch errors are contained;
  - hash ignores wall-clock-only snapshot churn;
  - schema constant.
- `tests/translation_policy_bootstrap_installer_test.ts`
  - installer propagates default/configured telemetry event globals.

## Invariant Notes

- Telemetry event emission remains opt-in.
- No DOM slot expansion.
- No additional mesh/network IO.
- Snapshot emission never mutates runtime state.
- Change detection excludes `now_ms` so frame-loop churn does not spam
  subscribers.
- No Rust/WASM/WGSL path touched.
