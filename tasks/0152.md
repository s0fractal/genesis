# Task 0152: Era 1660 — Translation Policy Wire Bridge

## Status: COMPLETED | Priority: HIGH

## Context
Era 1650 made translation-policy claims deterministic and monitorable,
but claims were still injected manually. Live peers needed a mesh payload
for publishing policy digests and feeding received claims into local
`TranslationPolicyMonitor` instances.

## Objective
1. Add translation-policy claim encoding/decoding helpers.
2. Provide a mesh bridge that sends local claims over caller-supplied
   plasmid emit callbacks.
3. Extend the V2 mesh semantic payload union.
4. Keep policy handling passive: delivery and event dispatch only.

## Acceptance Criteria

### 1. Mesh Helpers ✅
- [x] `decodeTranslationPolicyMeshPayload(...)` accepts valid
  `TranslationPolicyClaim` JSON.
- [x] Malformed JSON and malformed claim shapes return `null`.
- [x] `translationPolicyPlasmidFields(...)` produces target + body
  extension fields for plasmid construction.

### 2. Bridge ✅
- [x] `TranslationPolicyMeshBridge.broadcastLocalClaim(...)` sends the

- [x] Emit failures propagate without incrementing sent telemetry.
- [x] `handleIncoming(...)` decodes and forwards claims to

- [x] End-to-end test proves A's claim reaches B's monitor and creates

### 3. WebRTC Boundary ✅
- [x] `PlasmidPayload.semanticType` includes `TRANSLATION_POLICY`.
- [x] Payload fields `translationPolicyBody` and

### 4. Tests ✅
- [x] Targeted bridge + monitor tests pass.
- [x] `webrtc_v2.ts` type-checks with the expanded semantic union.

## Design Notes
- **Why not auto-observe inside `WebRTCV2Mesh`?** The mesh does not own
  operator policy state. It should deliver the claim; the app-level
  monitor decides how to observe, sink, and report drift.
- **Why JSON body like `EVENT_SYNC`?** This preserves the existing
  plasmid-extension style from Era 1510 and keeps binary frame slots
  reserved for substrate-level protocols.
- **Why passive event dispatch?** Policy drift is not yet a warrant.
  Era 1660 only makes the signal live; escalation belongs in the next
  bridge.
