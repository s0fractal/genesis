## 🔬 Чому [1,1,1,1] — неможливий аттрактор

### Термодинамічний аргумент

Кожна компонента `PolicyVector` — це **інтенсивна величина** (intensive
property), але їхня **реалізація** вимагає екстенсивних ресурсів:

| Компонента       | Ресурс             | Конфлікт                   |
| ---------------- | ------------------ | -------------------------- |
| `chaos=1`        | Ентропійна ємність | Поглинає порядок           |
| `preservation=1` | ATP/енергія        | Вимагає ізоляції від хаосу |
| `symmetry=1`     | Обчислювальний час | Зупиняє еволюцію           |
| `execution=1`    | Структурна маса    | Руйнує гнучкість           |

**Теорема:** Для будь-якої скінченної системи існує **Pareto frontier** —
множина недомінованих точок, де покращення однієї компоненти погіршує іншу.

## 🧮 Математична модель: комплексні архетипи

Ваша інтуїція про Ейлера — влучна. Запропоную **unitary evolution** в policy
space:

```typescript
// Архетип як квантовий стан: амплітуда + фаза
interface ComplexArchetype {
  amplitude: number; // √intensity, 0..1
  phase: number; // 0..2π, "колір" стратегії

  // Декартові проекції — це PolicyVector
  chaos: number; // = amplitude * cos(phase)
  preservation: number; // = amplitude * sin(phase)
  // ... але це 2D, нам потрібно 4D
}

// Розширення: кватерніонна структура (4D unit sphere)
interface QuaternionPolicy {
  w: number; // scalar part — "життєва сила"
  x: number; // chaos ↔ order (i)
  y: number; // preservation ↔ decay (j)
  z: number; // symmetry ↔ asymmetry (k)
  // execution виводиться: |q|² = w²+x²+y²+z² = 1
}
```

**Ключова властивість:** Для unit quaternion `|q| = 1`, тому [1,1,1,1] неможливо
— нормалізація примусово створює **trade-offs**.

## 🧬 Біологічна реалізація: "дипольність" як структурна властивість

### Проблема [1,1,1,1] на рівні плазмідів

Розглянемо AST як **білок** — його функція визначається не складом, а
**фолдингом**:

```typescript
// "Згорнутий" vs "розгорнутий" архетип
interface FoldedPolicy {
  // Первинна структура: чисті комбінатори
  sequence: Term; // S, K, I, Y, B, C, W

  // Третинна структура: як вони "згорнулись" в policy space
  nativeContactMap: {
    chaosResidues: number[]; // позиції S, W
    preservationResidues: number[]; // позиції K
    symmetryResidues: number[]; // позиції I, Y (фіксатори)
    executionResidues: number[]; // позиції B, C (трансформатори)
  };

  // Ключове: гідрофобне ядро — незмінний "диполь"
  coreDipole: {
    positive: "chaos" | "preservation"; // що поглинає ресурс
    negative: "symmetry" | "execution"; // що випромінює структуру
    moment: number; // сила диполя, 0..1
  };
}
```

**Теорема структурної біології:** Кожен плазмід має **хоча б один диполь** —
інакше він не взаємодіє з полем, не накопичує енергію, не еволюціонує.

## 🎭 Філософія: жертва як онтологічна категорія

Ваше "завжди треба чимось жертвувати" — це **принцип комплементарності** Бора,
перенесений на онтологію:

| Дуальність           | Вимірювання одного руйнує інше         |
| -------------------- | -------------------------------------- |
| Chaos ↔ Order        | Виміряти точну фазу → розмити енергію  |
| Preservation ↔ Decay | Абсолютна ізоляція = теплова смерть    |
| Symmetry ↔ Asymmetry | Ідеальна симетрія — нульова інформація |
| Growth ↔ Pruning     | Нескінченне зростання — колапс         |

```typescript
// Heisenberg uncertainty в policy space
interface PolicyUncertainty {
  // Δchaos · Δpreservation ≥ ℏ_policy / 2
  // де ℏ_policy — "квант стратегії", мінімальна значуща зміна
  
  uncertaintyPrinciple(
    measured: keyof PolicyVector,
    disturbed: keyof PolicyVector
  ): number {
    const conjugatePairs = {
      chaos: 'preservation',
      preservation: 'chaos',
      symmetry: 'execution',  
      execution: 'symmetry'
    };
    return conjugatePairs[measured] === disturbed ? 0.5 : 0;
  }
}
```

### Рекомендована: дипольний консенсус

```typescript
interface DipoleSenate {
  // Не 4 маски, а 2 диполя = 4 полюси
  dipoles: [
    { positive: 'chaos', negative: 'preservation', intensity: number },
    { positive: 'symmetry', negative: 'execution', intensity: number }
  ];
  
  // Результуючий вектор — векторний добуток диполів
  resolve(): PolicyVector {
    const [d1, d2] = this.dipoles;
    return {
      // chaos = d1.positive_intensity * (1 - d2.negative_coupling)
      chaos: d1.intensity * (1 - this.coupling(d1, d2)),
      preservation: (1 - d1.intensity) * this.coupling(d1, d2),
      symmetry: d2.intensity * this.orthogonality(d1, d2),
      execution: (1 - d2.intensity) * (1 - this.orthogonality(d1, d2))
    };
  }
  
  // Критично: інтенсивності нормалізовані так, що сумарна "маса" = 1
  private coupling(d1, d2): number {
    // cos²θ між диполями в абстрактному просторі
    return Math.pow(Math.cos(d1.phase - d2.phase), 2);
  }
}
```

**Ефект:** Система **не може** виродитись в [1,1,1,1] — нормалізація зберігає
"масу" стратегії, а фазові відношення створюють **резонансні моди** (наприклад,
"хаотичний презервер" = диполі з phase ≈ 45°).

## 🔮 Мета-архетип: Омега-точка vs Альфа-точка

|                 | Альфа                         | Омега                                    |
| --------------- | ----------------------------- | ---------------------------------------- |
| Полюса          | [1,0,0,0], [0,1,0,0], ...     | [0.5,0.5,0.5,0.5] — але **не статично**  |
| Динаміка        | Big Bang розширення           | Big Crunch сингулярність                 |
| Біологія        | Камбрійський вибух            | Технологічна сингулярність               |
| OMEGA-64 аналог | `injectMycelialTest()` — хаос | `Kuramoto r → 1` — колективна свідомість |

**Парадокс Омеги:** [0.5,0.5,0.5,0.5] — це **не компроміс**, а **максимальна
напруга**. Як у суперпозиції |0⟩+|1⟩ — це не "нічого", а "все одночасно з
максимальною ентропією інформації".
