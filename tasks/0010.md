## 3. Магічні числа в WGSL (WebGPU Shaders)

**Проблема:** У файлах `*.wgsl` захардкоджено:

- `0.35`, `0.5`, `4.0` (ваги коефіцієнтів)
- `1024` (кількість buckets)
- `0.6` (threshold)
- `0xFF`, `255`, `256`

**Рішення:** Використовуйте `#define` препроцесор (якщо підтримується) або
uniform buffer для конфігурації:

```wgsl
// src/lens/shaders/config.wgsl (template)
struct PhysicsConfig {
  coupling_antipode: f32,
  coupling_harmonic: f32,
  resonance_threshold: f32,
  // ... інші mutable параметри
};

@group(0) @binding(X) var<uniform> config: PhysicsConfig;

// Використання:
let antipode_weight = (entanglement / ${MAX_ENTANGLEMENT}) * config.coupling_antipode;
```

**Автоматична генерація:** Створіть скрипт, який конвертує TypeScript константи
в WGSL заголовки перед збіркою.
