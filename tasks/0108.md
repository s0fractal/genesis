# Task 0108: Era 1220 — Cross-Relay Investigation Convergence

## Status: COMPLETED | Priority: HIGH

## Context
Era 1210's deterministic `proposal_hash` means N relays observing
the same partition independently raise BYTE-IDENTICAL proposals.
The Senate's WarrantLedger naturally dedups them. But the count
of N — how many distinct relays converged on the same suspicion
— is itself a stronger signal than any individual alarm. Era 1220
surfaces that count as a first-class metric.

## Objective
For every observed `InvestigationRecord`, track how many DISTINCT
source relays raised it. Classify each proposal as `lone` /
`double` / `triple+` / `high` confidence based on corroboration
count. When a proposal reaches `high` confidence (default ≥3
distinct raisers), fire a callback so operators can act before
oracle ratification completes.

## Design Notes
- **Why corroboration matters BEFORE Senate ratification?** The
  Era 1090 Senate gate is intentional: 3 oracles must agree to
  formally quarantine. But corroboration is observable BEFORE the
  oracles vote — a proposal with 4 raisers is "more suspect" than
  one with 1, even if neither is yet ratified. Operators (and
  the Era 1140 reputation layer) can use corroboration as a soft
  pre-ratification deprioritization signal without bypassing the
  Senate's hard gate.
- **Why high_confidence_threshold ≥ 2?** Threshold of 1 is
  meaningless (always triggers). Threshold of 2 is the first
  point where corroboration is genuine. Default 3 mirrors the
  Senate's own oracle threshold.
- **Why FIFO eviction at 256?** A sustained high-traffic mesh
  generates new proposal_hashes whenever a partition flickers.
  256 records ≈ 4 minutes of sustained alarm at 1/sec, plenty for
  operator dashboards; older records are no longer actionable.
- **Why consensusSuspectTargets is a SOFT signal?** Quarantine
  requires Era 1210's `markWarranted`, which requires Senate
  ratification. Convergence is for HUDs, reputation deprioritization,
  and routing-layer awareness — never for unilateral action.
