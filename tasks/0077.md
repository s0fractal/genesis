### 1. Критичні виправлення (зробити негайно)

1. **Worker vs SharedWorker несумісність**
   - У `src/bootstrap/phase.ts` ви змінили на `new Worker(...)`, але в
     `renderClientLoop` і `WebRTCMesh` все ще використовується `MessagePort`.
   - **Проблема**: `worker.onmessage` працює, але
     `workerPort.addEventListener('message')` — ні (Worker не має
     `addEventListener` як MessagePort).
   - **Рішення**:
     ```ts
     // У bootstrap/phase.ts
     const worker = new Worker(...);
     worker.onmessage = (e) => { ... };           // вже є
     // Видалити workerPort.addEventListener('message'...
     // Замість нього використовувати worker.onmessage для всього
     ```

2. **Atomics.waitAsync в renderClientLoop**
   - Код є, але `watchFrames()` запускається тільки якщо `metadata.ring_buffer`
     існує. Потрібно передати цей буфер з Worker.
   - Додати в Worker-повідомлення `INIT_ACK`:
     ```rust
     // В lattice_worker.ts (якого немає в документі, але має бути)
     postMessage({
       type: 'INIT_ACK',
       metadata: { ..., ring_buffer: sab, slot_size: 4096 }
     });
     ```

3. **EthersATPBridge все ще може падати**
   - `ATP_TOKEN_ADDRESS = "0x0000..."` — фейковий. Замінити на реальну адресу
     контракту на Base Sepolia (або розгорнути свій).
