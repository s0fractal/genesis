# Task 0110: Era 1240 — Mesh Health Composite Score

## Status: COMPLETED | Priority: HIGH

## Context
The transport stack now exposes four distinct metrics:
`redundancy_rate` (Era 1180), partition alarm counts (Era 1200),
consensus suspect counts (Era 1220), quarantine counts (Era 1210).
Each is meaningful in isolation, but operators want a single
"is the mesh healthy?" number for HUDs and alerts.

## Objective
A composite score in `[0, 1]` per relay AND per mesh-as-a-whole,
deterministically computed from the existing metric streams.
Decomposable into itemized contributions for debug/HUD display.
Q16-encodable for SporeFrame transport (so composites can be
broadcast like any other resilience metric).

### 2. Score Formula ✅
```
redundancy        = stats.redundancy_rate × 0.55
partition_penalty = -min(0.30, alarms × 0.05)
consensus_penalty = -min(0.30, suspects × 0.10)
quarantine_penalty = -min(0.45, quarantined × 0.15)
no_data_floor     = 0.5 if total_intents == 0 else 0
score             = clamp[0,1](sum)
```

### 3. Health Bands ✅
- `healthy`  ≥ 0.75 — green
- `watch`    ≥ 0.50 — yellow
- `degraded` ≥ 0.25 — orange
- `critical` <  0.25 — red

## Design Notes
- **Why redundancy_weight = 0.55 (not 1.0)?** A perfect-redundancy
  mesh with no other observations should report ~"watch"
  (score 0.55), not "healthy" (≥0.75). Healthy requires either
  high redundancy AND good observability (no alarms / suspects /
  quarantines), or a small amount of every positive contribution.
  This forces operators to look at multiple signals before
  declaring victory.
- **Why no_data_floor = 0.5 when total_intents = 0?** A relay
  that just booted has no data; declaring it "critical" would
  be misleading. The floor reports it as "watch" (caution
  warranted, but no concrete evidence of failure).
- **Why max_quarantine_penalty = 0.45?** Quarantines are the
  loudest signal (Senate already ratified). 0.45 means three
  quarantines drop score by ~0.45 — pushing healthy meshes into
  "watch" territory. More than three (rare in practice) caps
  out — additional quarantines don't compound infinitely.
- **Why mesh score is a simple average?** Could use median,
  weighted-by-relay-traffic, etc. — but simple mean is
  deterministic, parseable, and operator-intuitive. Future
  versions can specialize.
