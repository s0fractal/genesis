# Task 0086: Era 1001 — Phase Routing Integration into P2P Mesh

## Status: OPEN | Priority: HIGH

## Context
Era 1000 foundation is complete (`omega_v2/src/routing.rs`):
- `PhaseAddress` (32-bit hierarchical)
- Hyperbolic distance (integer-only, Q3 fixed-point)
- Taylor step (first and second order)
- Greedy next-hop selection
- FFI exports for JS integration

## Objective
Integrate Phase Routing into the live P2P WebRTC mesh (`src/network/webrtc_v2.ts`) so that
plasmids (packets) are routed via phase-gradient wells rather than flat DHT/ID tables.

## Acceptance Criteria

### 1. JS Binding Layer (`src/bootstrap/v2.ts` or new `src/network/routing_bridge.ts`)
- [ ] Wrap FFI calls in a `PhaseRouter` class:
  - `getAddress(agentIndex: number): number`
  - `hyperbolicDistance(a: number, b: number): number`
  - `taylorStep(src: number, dst: number, maxStep: number): number`
- [ ] Cache neighbour addresses per peer connection (updated every 60 frames).

### 2. WebRTC Mesh Routing (`src/network/webrtc_v2.ts`)
- [ ] On receiving a `v2-sync` packet with `plasmid` payload:
  - Decode `targetAddress` from plasmid header.
  - Compute hyperbolic distance from **self** to `targetAddress`.
  - Compute hyperbolic distance from **each neighbour** to `targetAddress`.
  - If a neighbour is strictly closer, **forward** the plasmid instead of consuming it.
  - If self is the closest, consume the plasmid (apply intent/delta/injection).
- [ ] Prevent infinite forwarding loops:
  - Add `hop_count` and `max_hops = 8` to plasmid header.
  - Drop plasmids with `hop_count >= max_hops`.
  - Add `visited: number[]` (raw addresses) to detect cycles; drop if self already visited.

### 3. Compute Shader Integration (Optional but Recommended)
- [ ] Add `hyperbolic_distance` and `taylor_step` functions to `compute_v2.wgsl` or a new
  `routing.wgsl` module so that GPU threads can compute routing decisions in parallel
  for 1M+ agents.

### 4. Testing
- [ ] Deno integration test: simulate 3-node mesh, send plasmid from node A to node C
  via greedy phase routing through node B. Assert delivery within `max_hops`.
- [ ] Rust unit test: `test_greedy_route_1d_torus` — given a ring of 8 agents, route
  from index 0 to index 5 and assert the path follows phase gradient (not random).

## Design Notes
- Keep all routing math integer-only to maintain CPU-GPU-ZK determinism parity.
- `PhaseAddress` fits in a single `u32`, so plasmid header overhead is negligible (4 bytes).
- The 1D toroidal lattice means each agent has exactly 2 neighbours (left, right), making
  greedy routing trivial: always forward to the neighbour that reduces hyperbolic distance.
  For future 2D/3D lattices, `greedy_next_hop` will handle N neighbours.
