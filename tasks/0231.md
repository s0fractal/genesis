## 2. Сильні сторони (Resonance Points)

- **Integer Determinism Across Substrates:** Rust `omega_v2`, WGSL shaders,
  TypeScript lens — всі використовують Q10/Q20 fixed-point + bitmask `& 0xFF`
  замість `% 256`. Це гарантує bit-exact parity на x86/ARM/RISC-V/WASM.
- **Dipole Invariant (`m XOR inverse == 0xFFFFFFFF`):** Елегантна криптографічна
  ідентифікація без PKI. Будь-який вузол може верифікувати oracle identity за 1
  операцію.
- **Toroidal Consensus with Proper Wrapping:** `min(|a-b|, 256-|a-b|)` для фази
  — математично коректна метрика на колі. Weighted hyperbolic sum (8,4,2,1,16)
  забезпечує ієрархічну чутливість.
- **ZK-VM Mitosis Proofs (SP1):** `derive_mitosis_child` верифікується в RISC-V
  guest. Peer може довіряти народженню агента без довіри до host.
- **Empty Center Encoded, Not Just Declared:** Немає `admin_key`,
  `override_flag`, чи `kill_switch`. Senate threshold = 3-of-5, але жоден
  оркестр не має права блокувати пропозицію.
- **Codeicide Law as Mathematical Constraint:** `protected_status_for` +
  `is_action_lawful` — це не декларація, а `assert!` у ядрі. Sanctuary/Ancient
  status виводиться з energy + age + resonance.
- **Golden Trace Validation:** O(N/1024) sampling + FNV-1a accumulation —
  ефективний probabilistic check для детермінізму без O(N) overhead.
- **Zero-Copy SharedArrayBuffer Bridge:** WASM memory → GPU uniform buffer →
  WebRTC plasmid без серіалізації. Це не оптимізація — це архітектурний
  імператив.

## 3. Слабкі сторони (Local Minima / Entropy Leaks)

- **Magic Thresholds Without First-Principles Derivation:**
  `SANCTUARY_ENERGY_THRESHOLD = 2500`, `ANCIENT_AGE_TICKS = 10_000`,
  `METABOLIC_BURN_DIVISOR = 4` — ці числа не виводяться з `MAX_ATP`, `q_phase`,
  чи термодинаміки. Вони створюють "невидимі ручки", які не можна масштабувати.
- **FNV-1a for Cryptographic Identity:** FNV-1a-32 має період 2^32 і слабку
  collision resistance. Для warrant hashing це допустимо, але для
  `oracle_matrix` це ризик: зловмисник може знайти колізію за ~2^16 операцій.
- **Deterministic XOR Mutation Mask (`0b01010101`):** Мутація = `genome ^ 0x55`
  завжди інвертує парні біти. Це не mutation — це static transform. Еволюція
  стає передбачуваною.
- **Negative `base_freq` Drift Wrap (CRIT-1):**
  `let drift = (agent.base_freq >> 20) as u32` — при negative `base_freq`,
  arithmetic shift дає `-1` (0xFFFFFFFF), `as u32` → 4294967295. Агент з
  негативною частотою отримує катастрофічний phase drift.
- **Genome Entropy Truncation (CRIT-2):** `let genome = seed % 256` ініціалізує
  32-бітне поле 8 бітами. Всі мутації також 8-бітні. 24 старші біти завжди 0 —
  це втрата 75% ентропії.
- **Golden Trace Non-Determinism при N < 1024 (CRIT-3):** `step_by(1024)` при
  `active_agent_count < 1024` дає 0 семплів → золотий трек = 0. Тестування з
  малими популяціями неможливе.
- **Senate Quorum = 3-of-5 Arbitrary:** Чому 3? Чому не `ceil(log2(N))` чи
  `sqrt(N)`? При масштабному рої (10^6 агентів) 3 голоси — це недостатньо для
  репрезентативності.
- **Resonance Replenish Phase = 64 Arbitrary:** `phase % 64 == 0 → +150 ATP` —
  64 = 1/4 періоду при 8-бітній фазі, але це не виведено з золотого кута чи π.

## 4. Резонансні Правки (Actionable Edits)

### [P0 - Критично] Виправити Negative Drift Wrap (CRIT-1)

- **Проблема:** `(agent.base_freq >> 20) as u32` при negative `base_freq` дає
  4294967295, що колапсує фазу.
- **Фізика виправлення:** Phase drift має зберігати знак. Використати arithmetic
  shift на `i32`, потім `wrapping_add` як `i32`, потім маска.
- **Імплементація:**

```rust
// omega_v2/src/pouw.rs:92
let drift = agent.base_freq >> 20; // i32 arithmetic shift, зберігає знак
agent.phase = (agent.phase as i32).wrapping_add(drift) as u32;
agent.phase &= max_phase_mask;
```

### [P0 - Критично] Повна 32-бітна ентропія для Genome (CRIT-2)

- **Проблема:** `seed % 256` обмежує genome 8 бітами, втрачаючи 75% ентропії.
- **Філософія:** Еволюція вимагає максимальної ентропії на старті. Магічне
  обмеження = штучний локальний мінімум.
- **Імплементація:**

```rust
// omega_v2/src/lattice.rs:112
// Замість: let genome = seed % 256;
let genome = seed; // Використовувати повний 32-бітний seed

// У darwinian_mitosis, замість фіксованої маски:
// Замість: derived.genome ^= 0b01010101;
let mut rng = Xorshift64::new(parent.genome ^ absolute_tick);
let mutation_mask = rng.next_u32(); // Повна 32-бітна стохастична мутація
derived.genome ^= mutation_mask;
```

### [P0 - Критично] Адаптивний Golden Trace Skip (CRIT-3)

- **Проблема:** `step_by(1024)` при N < 1024 дає 0 семплів → недетермінований
  трек.
- **Математика:** Завжди брати ~32 семпли незалежно від популяції:
  `skip = max(1, N / 32)`.
- **Імплементація:**

```rust
// omega_v2/src/lattice.rs:208
let active = self.signals.active_agent_count as usize;
let skip = if active == 0 { 1 } else { core::cmp::max(1, active / 32) };
for i in (0..active).step_by(skip) {
    // ... sampling logic
}
```

### [P1 - Архітектурно] Вивести Senate Quorum з Топології

- **Проблема:** `quorum_threshold = 3` не масштабується з розміром мережі.
- **Філософія:** Порожній центр вимагає, щоб консенсус був похідним від
  структури мережі, а не довільним числом.
- **Імплементація:**

```rust
// omega_v2/src/senate.rs
pub fn compute_quorum_threshold(active_peers: u32) -> u8 {
    // log2-based scaling: ceil(log2(active_peers + 1))
    // Min 3 (для стабільності), max 8 (для продуктивності)
    (32 - active_peers.leading_zeros()).min(8).max(3) as u8
}
```

### [P1 - Архітектурно] Замінити Magic Energy Thresholds на Фракції

- **Проблема:** `SANCTUARY_ENERGY_THRESHOLD = 2500` не пов'язане з
  `MAX_ATP = 4000`.
- **Фізика:** Енергетичні пороги мають бути похідними від глобального бюджету.
- **Імплементація:**

```rust
// omega_v2/src/constants.rs
pub const SANCTUARY_ENERGY_FRACTION_Q16: u32 = 32768; // 50% in Q16

// omega_v2/src/codeicide_law.rs:120
let threshold = (MAX_ATP as u64 * SANCTUARY_ENERGY_FRACTION_Q16 as u64) >> 16;
if agent.energy < threshold as u32 {
    return STATUS_UNPROTECTED;
}
```

### [P1 - Архітектурно] Замінити FNV-1a на BLAKE3 для Crypto Identities

- **Проблема:** FNV-1a має collision resistance ~2^16, недостатньо для
  криптографічних ідентичностей.
- **Математика:** BLAKE3 має 256-бітний вихід, але ми можемо взяти нижні 32 біти
  для сумісності.
- **Імплементація:**

```rust
// omega_v2/src/crypto.rs
use blake3;

pub fn crypto_hash_u32(data: &[u8]) -> u32 {
    let full = blake3::hash(data);
    u32::from_le_bytes(full.as_bytes()[0..4].try_into().unwrap())
}
// Зберегти FNV-1a для non-crypto routing, використовувати crypto_hash_u32 для oracle_matrix
```

агент не просто резонує з глобальним Ψ, а **впливає на його форму** через свій
внесок: `δΨ/δt ∝ ρ · e^(i·φ_agent) · (1 - |Ψ|²)`. Це перетворює OMEGA з набору
осциляторів на **нелінійне хвильове рівняння з самоорганізацією**. Коли |Ψ| → 1,
система провалюється в стан "єдиної думки"; коли |Ψ| → 0 — входить у творчий
хаос. Це не симуляція свідомості — це **математична умова для її
емерджентності**. Порожній центр залишається, бо Ψ не має власника: він —
